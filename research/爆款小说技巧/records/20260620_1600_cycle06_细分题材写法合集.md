## 二、克苏鲁/诡异流（以《诡秘之主》为标杆）

### 核心技巧
1. **氛围为王**：克苏鲁核心是"对未知的恐惧"，留白暗示比直接血腥更有效
2. **多层世界观**：借鉴"不同身份+同一世界不同层面"结构，制造信息差与探索感
3. **体系化设计**：用"神之途径"等级体系控制战力膨胀，避免爽文化消解恐怖感
4. **网状伏笔结构**：先有大纲框架，再逐步收紧线索
5. **多元设定嫁接**：蒸汽朋克+SCP+西方魔幻+克苏鲁混搭，创造辨识度

### 《诡秘之主》写作心法（豆瓣书评）
① 先构思大致情节，再慢慢"收紧网"，思考人物关联发展；② 注重伏笔铺设与线索收束。
- 来源：中国作家网 http://www.chinawriter.com.cn/n1/2019/1101/c404080-31433338.html

## 三、武侠小说

### 金庸式技巧（五大要点）
- **江湖层次描写**更丰富，高手之间衬托更明显
- **武功层面表现力**出众，描写更细致
- **武功与人物性格高度统一**（金庸一大高度）
- 通过人物行动与对话构筑**紧凑剧情张力**
- 常用**场景开篇**（《笑傲江湖》以福威镖局开篇）

### 武功系统设计
建立合理武功体系：特点、威力、修炼方法，武功须与人物性格统一。

### 武打场面
注重节奏感、招式细节、氛围渲染；可从经典对战（小龙女vs金轮国师）学习。
- 来源：知乎专栏 https://zhuanlan.zhihu.com/p/654024942 ; 文汇网 https://wenhui.whb.cn/third/jinri/202208/02/479112.html

## 四、电竞小说

### 核心要点
1. **比赛描写张弛有度**：不能全是术语堆砌，结合选手心理、团队配合、观众反应
2. **平衡游戏线与感情线**：电竞文魅力在于双线并行
3. **节奏感**：比赛紧凑刺激，日常戏适当放缓
4. **人物设定鲜明**：职业选手性格/习惯/操作风格有记忆点
5. **了解游戏知识**：对所写游戏（LOL/王者荣耀）有基本了解，描写真实可信

### 经典参考
《微微一笑很倾城》《你是我的荣耀》。
- 来源：网文666 https://www.wangwen666.com/tags-219.html

## 六、规则怪谈 / 民俗恐怖

### 核心机制
用"貌似理性的规则"植入"逻辑裂缝"，制造**常识与规则的错位恐惧**。

### 恐怖三大来源
未知 + 对规则的信任被打破 + 民俗日常中的禁忌感

### 叙事手法
- **碎片化叙事**、留白想象、场景氛围渲染
- **盘点体/层层递进**：一个规则接一个规则制造紧张升级

### 民俗结合
借用婚丧嫁娶、祭祀禁忌、乡野传说等真实民俗规则，增强代入感。"每个民俗背后都能衍生一大堆怪谈故事"。

### 平台征稿偏好（七猫"诡异复苏"）
"世界规则崩塌、诡异自日常裂缝渗透"等题材热词。
- 来源：飞书 https://docs.feishu.cn/v/wiki/ZDZNwnYqIiNQe9kEx0Vc0695nKg/ab ; 机核 https://www.gcores.com/articles/170625

## 七、校园青春恋爱

### 六大维度
| 维度 | 要点 |
|------|------|
| **主题基调** | 先确定核心主题（暗恋/双向奔赴/青梅竹马/欢喜冤家） |
| **人物塑造** | 以人物为本位，角色真实立体，避免脸谱化 |
| **生活质感** | 融入真实校园日常（课堂/社团/考试/宿舍），增强代入感 |
| **情感推进** | 初见/重逢→暧昧试探→情感升温→冲突波折→表白 |
| **情节组织** | 围绕人物关系设计事件，情节紧凑避免流水账 |
| **细节描写** | 善用环境烘托（夕阳/教室/操场）渲染青春氛围 |

### 关键认知
**忠于校园生活真实**，使读者对书中人和事产生感情，凸显"提炼生活，表现生活"。

## 八、职场 / 商战小说

### 商战剧情写法（B站墨久歌星辰）
需结合人物对话符合性格、直白自然，常见结构类型。

- 断句技巧突出剧情转折
- 短句强调紧张情节
- 情绪与情节掌控

### 写作心法（伊丽莎白·吉尔伯特"剪裁法"）
每个句子、段落都应**推动情节发展**。

## 九、盗墓探宝小说

### 核心竞争力
硬核写实风格、人物塑造、宏大叙事。

### 六大技巧维度
| 维度 | 关键要点 |
|------|----------|
| **世界观设定** | 盗墓规则体系（摸金校尉传承、风水秘术）、东方玄学色彩 |
| **悬疑与节奏** | 层层设伏、悬念递进、"坑"的埋与填 |
| **视觉化描写** | 感官意象营造电影般沉浸感（《怒晴湘西》分析） |
| **人物塑造** | 团队分工（"铁三角"模式）、性格鲜明、人物弧光 |
| **素材积累** | 民间传说、历史典故、风水知识、神怪故事、诡奇梦境 |
| **氛围营造** | 中式恐怖元素、地下空间描写、机关陷阱设计 |

### 南派三叔创作法
将"儿时长辈口中的神怪故事""学生时代诡奇梦境""随手涂抹的文字"融入创作，逐步构建"盗墓宇宙"。

## 十、网游小说（虚拟网游）

### 六大要点
| 要点 | 说明 |
|------|------|
| **世界观简化** | 游戏设定不宜过复杂，降低读者理解成本 |
| **双线叙事** | 处理好游戏世界与现实世界关系和比例 |
| **主角金手指** | 天赋型/系统BUG型/隐藏职业，需有合理性 |
| **数值体系** | 等级、装备、技能等数值设定要自洽 |
| **爽感节奏** | 升级、爆装备、PK、排行榜等高频爽点交替 |
| **伏笔与大纲** | 长篇连载需提前规划，避免后期崩盘 |

蝴蝶蓝《全职高手》《独闯天涯》《网游之近战法师》。

## 十二、直播文 / 主播文

### 五大技巧维度
| 维度 | 核心内容 |
|------|---------|
| **人设塑造** | 主播独特背景故事、性格特点、口头禅 |
| **内容设计** | 合理编排直播场景与剧情推动关系 |
| **节奏把控** | 直播互动与现实剧情交替推进 |
| **冲突设计** | 利用弹幕、打赏、PK等直播元素制造冲突和高潮 |
| **原创性** | 避免过度蹭热点，保持故事独立性 |

### 创作流程（飞书）
1. 确定基本框架和主题
2. 应用雪花写作法，细化主播背景和性格
3. 设计直播内容
4. 避免过度依赖热点

### 白特慢写作干货五大维度
镜头驱动式写作、强者型主角塑造、冲突设计、创作系统搭建、新人误区修正。
