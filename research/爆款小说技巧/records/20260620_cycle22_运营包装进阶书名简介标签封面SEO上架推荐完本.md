## 一、书名取名进阶（爆款公式/平台差异）

书名是算法推荐的第一道门槛，需在 **0.1 秒内** 完成"题材 + 爽点 + 差异化"三重信息传递，直接决定首日阅读量。

### 平台差异对照（番茄 vs 起点）

| 维度 | 番茄小说（免费/广告变现） | 起点中文网（付费阅读） |
|------|--------------------------|----------------------|
| 受众 | 泛用户、下沉市场 | 核心网文读者 |
| 书名要求 | 更直白、抓眼球、即时爽感 | 可适度含蓄、世界观暗示 |
| 推荐机制 | 算法驱动，书名=流量入口 | 编辑推荐 + 圈层口碑 |
| 书名长度 | 短平快、信息密度高 | 包容性更强 |

### 可直接抄的爆款公式

1. **身份反差型**："我是 XX 但 XXX"
2. **数据冲击型**：数字 + 夸张结果
3. **悬念钩子型**：制造认知冲突
4. **标签叠加型**：核心标签 + 差异化标签

### 高频踩雷区

- 书名太文艺/太含蓄 → 读者看不懂题材
- 书名太长 → 移动端显示不全
- 书名与内容不符 → 留存率反噬推荐

## 二、简介文案写作（一句话简介/卖点提炼）

编辑审稿看简介只问三件事：有没有**商业潜力**、是否踩中**热门赛道**、能不能写出**差异化**。番茄官方明确要求简介必须"体现卖点"，让编辑/读者 **3 秒内 get 到核心亮点**。

### 可操作要点

| 要点 | 具体做法 |
|------|---------|
| 一句话简介公式 | 主角身份 + 核心冲突 + 最大爽点（3 秒读完） |
| 卖点提炼来源 | 从"设定、金手指、反差、情感钩子"中选 1-2 个最强元素 |
| 卖点前置 | 最大卖点应尽早出现在简介开头，不要藏 |
| 前 300 字 | 让编辑一眼看懂"谁是主角、在做什么" |
| 对标法 | 找同赛道 3-5 本火文，拆解对方简介结构再套用 |

### 致命避坑

- **不要写启发式问题**（如"她能否逆天改命？"）→ 直接亮卖点
- 不要把卖点藏着掖着搞"悬念营销"

## 三、标签选择（题材标签/流量标签）

标签已从"对作品类型的简单划分"进化为"**以爽点标识为目的的流量分发符号系统**"，直接参与推荐算法决策。

### 三层标签组合策略

| 标签类型 | 功能 | 示例 |
|---------|------|------|
| 题材标签（核心定位） | 定义作品类型方向 | 玄幻、都市、言情、科幻 |
| 元素/主题标签（卖点标识） | 突出核心爽点 | 系统流、重生、穿越、宫斗、末世 |
| 流量标签（曝光助推） | 紧跟平台扶持方向 | 现实题材、乡村振兴、主旋律 |

### 操作要点

1. **精准聚焦型**：垂直领域选 2-3 个精准题材标签，吸引目标读者
2. **组合策略**：题材标签 + 元素标签 + 热门标签，兼顾精准与广度
3. **避坑**：标签过多、与内容不相关会稀释推荐效果
4. **趋势**：2024 年起现实题材、主旋律标签获更多平台流量倾斜

## 四、封面设计（封面风格/首图吸引力）

封面设计的本质是"**信息传递效率**"与"**视觉吸引力**"的平衡，核心目标是抓注意力 + 表达主题。

### 视觉焦点排序（黄金顺序）

> **图像/图形 → 颜色 → 文字**

先确立与题材相关的图形定基调，再用互补色增强冲击力，最后排文字。

### 五步实操流程

1. 了解封面结构 → 2. 决定**主色调**定风格 → 3. 选符合调性的字体 → 4. 安排插图 → 5. 合理排布元素

### 风格匹配建议

| 题材 | 推荐风格 | 关键元素 |
|------|---------|---------|
| 青春冒险 | 潮酷风 | 大胆色彩 + 现代感字体 |
| 仙侠古风 | 古风 | 国风元素 + 书法体 |
| 都市言情 | 清新/简约 | 柔和配色 + 优雅排版 |

### 字体六要点
字体风格匹配、可读性与层次感、色彩情感融合、创意排版、版权意识、测试反馈优化。

## 五、关键词 SEO 与热词布局

网文 SEO 核心流程：**选词 → 拓展 → 布局 → 排名 → 流量转化**。关键词选择是首要环节。

### 关键词分类

| 类型 | 特点 | 作用 |
|------|------|------|
| 核心词 | 流量大、竞争激烈 | 主流量入口 |
| 长尾词 | 转化高、竞争小 | 精准获客 |
| 热词 | 时效性强 | 短期爆发 |

### 布局位置（按权重排序）

书名 → Title 标签 → 导航/分类 → 正文首段 → H 标签 → 内链锚文本

### 热词挖掘方法

1. 利用平台**搜索建议/下拉词**
2. **竞品关键词**分析，借势投放热度
3. 模拟用户搜索行为挖掘
4. 站内榜单热词反查

### 布局原则

- **自然融入**，避免堆砌
- 避免**关键词蚕食**（同一词重复布局到多页面互相竞争）
- 内容与搜索意图高度匹配

## 六、上架技巧（上架时机/VIP 章节定价）

**上架 = 入 VIP（入 V）**，上架后章节读者需付费购买，是付费阅读平台的核心收入来源。

### 上架时机判断

| 指标 | 标准 |
|------|------|
| 字数 | 一般 10-20 万字达平台要求 |
| 数据 | 收藏、追读达标 |
| 关键指标 | **首订**（首章发布后 24 小时订阅量）反映上架初期热度 |

### 上架技巧

1. 保证**稳定更新**（拿全勤奖，签约即有，不必等上架）
2. 上架前积累**推荐资源**
3. **上架当天爆更**拉首订
4. 选择适合自己题材的平台（不同平台门槛/资源差异大）

### VIP 定价要点

- 各平台按**千字计费**，标准不同
- 定价需平衡读者消费能力与作者收益
- 定价过高会大幅降低订阅率
- 阅文作者收入构成：**订阅 + 全勤（日更 4000 字）+ 勤奋写作 + 道具分成 + 月票**

### 平台对比

- **起点**：付费阅读成熟，读者书龄长，对故事精细度和逻辑严谨性要求高
- **番茄**：免费阅读，广告变现，靠算法分发
- **新人扶持**：按日更字数（3000/6000/9000 字）分三档，分别奖励当月 VIP 收入的 5%/10%/15%

## 七、推荐位获取（推荐机制/编辑推荐）

### 付费平台（起点）：编辑 + 追读数据 PK

- 编辑每周根据签约书的**追读数据**顺位 PK，前列者获推荐位，展示在"分类内的人气连载"，新书期流量最大
- 后续每周继续顺位 PK 晋级
- 推荐**周五至周日下午两点前**由系统发送至作者后台邮箱，**不接受私聊问推荐**
- 2026 年 2 月起点终止试行 7 个月的"流量包"模式，回归传统"**4 轮 PK**"机制
- 编辑负责安排推荐位，**话语权大**

### 免费平台（番茄）：纯算法滚雪球

- 系统先圈定一部分读者展示作品，再根据这部分读者的**行为数据**继续圈定同类型读者，不断扩大推荐量
- 算法根据**留存率、阅读时长**等数据决定推荐量
- 采用"**滚雪球**"式扩圈策略：数据越好曝光越多
- 编辑只负责签约和流程服务，**纯服务型**，推荐完全由算法决定

### 算法技术逻辑

两种核心推荐算法：**基于内容的推荐**（依赖网文本身特征）+ **协同过滤**（依赖用户行为相似性）。

### 双平台对比速查

| 维度 | 付费平台（起点） | 免费平台（番茄） |
|------|-----------------|-----------------|
| 推荐决策者 | 编辑 + 追读 PK | 算法自动分发 |
| 核心数据指标 | 追读、收藏、订阅 | 留存率、阅读时长 |
| 编辑角色 | 安排推荐位，话语权大 | 仅签约，纯服务型 |
| 推荐触发 | 每周顺位 PK 晋级 | 系统扩圈式滚雪球 |

## 八、完本运营与 IP 孵化

网文本身约 300 亿元产值，但**网文 IP 版权运营市场规模已超 2520 亿元**（2022 数据），完本后的 IP 运营才是真正的价值放大器。

### 六大核心策略

| 策略 | 具体做法 |
|------|---------|
| **IP 孵化前置** | 作品创作早期即规划 IP 化路径，提升系列化开发质量 |
| **完本运营维持热度** | 完结后通过线上发新动向 + 线下办活动，填补 IP 改编空窗期，维持粉丝黏性 |
| **共营合伙人模式** | 从"作者制作人"进化为多方协同的 IP 生态运营（基于一个 IP，一群人共同推动） |
| **多平台孵化布局** | 短篇/长篇均采用多平台推广策略（如椿和文化"鸥知读书"模式） |
| **可视化破局** | 前置化的高质量"可视化"呈现是 IP 化突围、抓新品类机会的关键 |
| **微短剧改编** | 竖屏小程序剧 + 横屏短剧产业蓬勃发展，是完结网文 IP 的新改编路径 |

### 大阅文战略

基于腾讯新文创生态，以网络文学为基石、IP 开发为驱动力，开放性与全行业合作伙伴共建 IP 生态矩阵。旗下囊括起点读书、新丽传媒、QQ 阅读、腾讯动漫、阅文好物等，已成功输出《庆余年》《鬼吹灯》等头部 IP。

1. **书名是流量第一道闸门**：0.1 秒传递"题材 + 爽点 + 差异化"；番茄要直白爽快，起点可含蓄但忌过长、忌名实不符。
2. **简介只解决三件事**：商业潜力 + 热门赛道 + 差异化；一句话公式 = 主角身份 + 核心冲突 + 最大爽点；坚决不写启发式问题，卖点前置。
3. **标签已升级为"爽点符号系统"**：题材 + 元素 + 流量三层组合，紧扣平台扶持方向（现实题材/主旋律有红利），忌堆砌。
4. **封面视觉焦点固定顺序**：图像 → 颜色 → 文字；互补色 + 题材匹配风格是首图吸引力关键。
5. **SEO 流程闭环**：选词 → 拓展 → 布局 → 排名 → 转化；核心词 + 长尾词 + 热词分层布局到 Title/首段/H 标签，自然融入防蚕食。
6. **上架 = 入 VIP**：字数 10-20 万 + 首订是关键指标；当天爆更拉首订，靠全勤/勤奋奖托底；定价按千字计费，平衡消费能力。
7. **推荐机制双轨**：起点靠编辑 + 追读 PK（每周顺位晋级，话语权在编辑）；番茄纯算法滚雪球（看留存和时长，编辑只服务）。
8. **完本才是价值放大器**：IP 孵化前置 + 完结线上/线下运营 + 共营合伙人模式 + 多平台布局 + 可视化破局 + 微短剧改编；网文本体 300 亿，IP 运营市场超 2520 亿。
