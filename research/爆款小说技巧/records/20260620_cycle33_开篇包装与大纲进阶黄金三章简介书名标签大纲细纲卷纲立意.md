## 一、开篇黄金三章（第一章怎么写/抓住读者）

**核心理念**：开篇 3 秒定生死，前 300 字 = 命运分水岭。黄金三章的本质是在读者耐心耗尽前，用最短路径抛出"爽点 + 悬念 + 主角光环"。

### 可操作要点

| 技巧 | 说明 |
|------|------|
| **开局300字钩子** | 用新奇设定、主角困境、家族变故或仇恨主线，第一段就制造"非读不可"的张力 |
| **聚焦主角** | 开篇只写主角，减少无关人物出场，避免信息过载让读者出戏 |
| **冲突前置** | 不平铺直叙背景，用冲突（被退婚/被流放/被追杀）直接抓住注意力 |
| **人设反差** | 通过身份反差（如废柴+隐藏天赋、工科生+穿越）让读者快速记住主角 |
| **悬念收尾** | 每章结尾留钩子，驱动读者点下一章（章末"反转/悬念/未解之谜"） |
| **兴奋点密集** | 第一章就抛出密集兴奋点，《斗破苍穹》第一章易稿二十几次就是经典案例 |

## 二、简介文案写作（一句话卖点/卖点提炼）

**核心理念**：简介是书名的"放大版"，第一句话必须点明"谁 + 经历什么"，把最大卖点（神奇物品/特殊设定/爽点钩子）前置到简介第一段。

### 可操作要点

| 技巧 | 说明 |
|------|------|
| **第一段定生死** | 第一句就写"主角身份 + 开局困境"，如"被家族流放的庶女""刚穿书就要被退婚的工科生"，不铺垫、不描写环境 |
| **标签先行** | 直接给标签（流放庶女/退婚/工科穿书），快速告诉读者"这是什么类型" |
| **卖点前置** | 最大卖点（金手指/系统/奇遇/逆袭）必须尽早出现在简介中 |
| **突出萌点爽点** | 简介比书名更详细地告诉读者梗概，核心是放大萌点和爽点 |
| **文案"集中"原则** | 标题唯一目的 = 让读者读第一句话；第一句话唯一目的 = 让读者读第二句 |
| **借产品卖点方法论** | 卖点提炼上承"细分市场（读者群）+ 目标人群 + 竞品分析 + 价值体系"，这套逻辑同样适用于网文定位 |

## 三、书名取名技巧（爆款书名公式/平台差异）

**核心理念**：书名 = 最高权重的"一句话卖点"。免费平台靠"直白爽感"骗点击，付费/传统平台靠"格局暗示"定调性。书名必须匹配平台读者画像。

### 八大平台书名风格对照

| 平台 | 风格特点 |
|------|----------|
| **番茄** | 免费爽文，书名直白、强调"金手指/爽感"，常用"开局/重生" |
| **起点** | 传统男频，书名可稍长，注重格局感和世界观暗示 |
| **晋江** | 女频为主，偏文艺、情感化，常用诗意向或角色名+情境 |
| **飞卢** | 同人/脑洞大，书名追求猎奇夸张，强调"系统/穿越" |
| **七猫** | 免费平台，简单粗暴、一眼看懂卖点 |
| **纵横** | 传统男频，风格介于起点和免费平台之间 |
| **QQ阅读** | 综合性，书名需兼顾大众化 |
| **书旗** | 偏免费渠道，风格类似七猫 |

### 5个爆款书名公式

1. **身份/职业 + 反差事件** → "开局：我成了xxx的xxx"
2. **金手指/系统 + 爽点结果** → "开局签到xxx亿"
3. **痛点/困境 + 逆袭反转** → "被xxx后，我xxx"
4. **热点标签组合** → "重生+赘婿+打脸"
5. **悬念/疑问式** → "我居然xxx了？"

### 3类高频踩雷

- 过于文艺晦涩（免费平台点击率腰斩）
- 书名过长/信息过载（超15字被截断，卖点被遮盖）
- 标题党与内容不符（完读率和推荐量被惩罚）

## 四、标签选择（题材标签/流量标签/撑场）

**核心理念**：标签是平台的"流量分拣器"。理解三级标签体系 + 流量池机制，才能让作品精准进入目标读者池。"撑场"指用热门流量标签为作品撑起初始曝光，但需避免标签与内容错配导致完读率崩盘。

### 可操作要点

| 要点 | 说明 |
|------|------|
| **三级分类体系** | 一级：频道（男频/女频）→ 二级：题材（玄幻/都市/言情）→ 三级：元素标签（重生/系统/甜宠）。单一元素无法定义作品，每部小说是"多元素组合" |
| **流量池机制** | 番茄等免费平台签约后**不允许作者修改标签**，由平台根据数据自动调整，可能导致标签偏离创作意图 |
| **标签筛选价值** | 对读者：相当于"内容预告"，精准匹配阅读期待，降低选书成本；对作者：降低新人起步门槛 |
| **圈层陷阱** | 过精细标签会加深用户圈层（喜欢现代言情的读者不会打开其他类型），选题时要权衡 |
| **题材融合趋势** | 2024年科幻类型网文发展迅猛，题材融合与文体创新（如"科幻+修仙"）彰显活力 |
| **撑场策略** | 选 1-2 个高流量标签（题材大词）撑曝光 + 2-3 个精准元素标签锚定核心读者，避免"全热门标签"导致转化率低 |

## 五、大纲写作技巧（三幕式/救猫咪节拍）

**核心理念**：大纲 = 故事骨架。三幕式（建置→对抗→结局）是通用框架，救猫咪节拍表把三幕细分为 15 个节奏点，可精准控制网文卷纲与章节节奏。注意：方法论是脚手架，不应一成不变照搬。

### 救猫咪三幕式 15 个节拍

| 幕 | 节拍 |
|----|------|
| **第一幕·建置** | 开场画面、主题呈现、铺垫、触发事件、质疑犹豫 |
| **第二幕·对抗** | 进入第二幕、副线故事、有趣游戏、中点、坏人逼近、失去一切、灵魂黑夜 |
| **第三幕·结局** | 进入第三幕、高潮、结局画面 |

### 可操作要点

| 要点 | 说明 |
|------|------|
| **三幕式骨架** | 建置→对抗→结局，是所有结构方法（英雄之旅、雪花算法）的共同基底 |
| **"救猫咪"含义** | 主角在故事早期做出某些行为（如救一只猫），让读者对其产生同情和好感 |
| **页数比例控制** | 斯奈德假定剧本110页，给出每个节拍对应的页数比例，帮助作者精准控节奏 |
| **网文映射** | 可将15个节拍对应到小说卷纲/章节规划，控制悬念和情绪起伏 |
| **关键节拍优先** | 开场画面、触发事件、中点、灵魂黑夜、高潮是必须打磨的5个核心点 |
| **灵活变通** | 节拍表是参考而非教条，网文长篇连载可拆分为多个"小三幕"循环 |

## 六、细纲/章纲写作（每章写什么）

**核心理念**：大纲→细纲→章纲是"从宏观到微观"的严谨体系。细纲 = 大纲的具体化，精确到每一章。经验法则：3000字章节的细纲**不超过100字**。

### 每章细纲应包含的三大块

1. **情节**：情节名称 + 情节作用（每个情节都必须有作用，如为高潮铺垫/解释前因后果，明确作用可避免无用情节）
2. **人物与场景**：涉及人物、场景地点
3. **落点与钩子**：核心冲突推进、本章落点/钩子（章末留悬念）

### 章纲模板示例

```
第X章：[章节主题/核心事件]
- 涉及人物：
- 场景地点：
- 核心冲突/推进：
- 本章落点/钩子：
```

### 可操作要点

| 要点 | 说明 |
|------|------|
| **字数控制** | 3000字章节细纲 ≤ 100字，写多了说明在写正文不是写纲 |
| **三次创作法** | 大纲=第一次灵感创意，细纲=第二次，具体创作=第三次 |
| **贴卖点推进** | 每章细纲都要时刻贴近"核心卖点"推进剧情 |
| **每章有贡献** | 确保每一章落点都对整体故事有贡献，删掉无用章节 |
| **5种经典结构** | 三幕式（通用）、升级打怪（网文最常用）、悬疑推理（线索驱动）等 |
| **写作五步流程** | 题材卖点 → 梗概主线 → 人设 → 大纲细纲 → 开篇三章 |

## 七、卷纲设计（分卷规划/卷末钩子）

**核心理念**：百万字长篇必须分卷。分卷 = 按"情节发展"或"地图变换"切分，每卷有独立主题、目标和核心矛盾。卷末钩子是驱动读者"非看下一卷不可"的核心武器。

### 可操作要点

| 要点 | 说明 |
|------|------|
| **分卷依据** | 按情节发展或地图变换划分，每卷20-30万字为宜 |
| **每卷四要素** | 独立主题 + 独立目标 + 需解决的核心矛盾 + 明确的起始/结束标志 |
| **卷末钩子设计** | 在卷尾设置悬念、反转或新冲突，制造"非看下一卷不可"的驱动力 |
| **爽点密度规划** | 卷内爽点要分布均匀，避免长段落拖沓导致流失 |
| **情绪曲线管理** | 每卷内部也要有起承转合（小型三幕），不能平铺 |
| **反向学习** | 用AI拆书工具拆解成功作品的分卷结构，学习其卷纲节奏 |

### 分卷规划结构示意

```
第X卷：[卷主题]
- 卷起始标志：
- 核心矛盾：
- 主线目标：
- 卷末钩子：
- 预估字数：
```

## 八、立意主题（思想内核/价值观传达）

**核心理念**：立意 = 小说传达的精神思想，是"文以载道"的现代表达。网络文学正从"模仿经典→讲故事→现实观照"三级跳深化，思想内核决定作品能走多远、能否成为经典。但也要警惕低俗化、过度商业化削弱精神价值。

### 可操作要点

| 维度 | 核心内容 |
|------|----------|
| **立意定义** | 小说传达的精神思想，弘扬真善美、针砭时弊，承载社会价值 |
| **思想内核深化** | 从模仿经典（作者时段）→ 创生网络故事（写手时段）→ 现实观照（作家时段）逐层升级 |
| **价值观传达途径** | 弘扬真善美、家国情怀、拼搏精神，融入五千年传统文化（网文是"性价比最高的精神文明载体"） |
| **创作导向** | 以人民为中心，从中华优秀传统文化汲取营养，守正创新，向主流化发展 |
| **现实题材发力** | 坚持思想精深、艺术精湛、制作精良相统一，讴歌党/祖国/人民/英雄 |
| **风险警惕** | 避免低俗化、过度商业化对思想内核的侵蚀，引导读者吸收积极向上价值观 |

## 本轮核心结论速记

1. **开篇是命门**：前300字定生死，"冲突前置 + 聚焦主角 + 章末钩子"是黄金三章铁律，参考《斗破苍穹》第一章易稿二十几次。
2. **书名与简介是"放大版卖点"**：书名匹配平台调性（免费平台直白爽感/付费平台格局暗示），简介第一句必须点明"主角身份+开局困境"，最大卖点前置。
3. **标签是流量分拣器**：理解三级标签体系（频道→题材→元素）+ 流量池机制（番茄签约后不可改标签），用"1-2个高流量大词撑场 + 2-3个精准元素锚定读者"。
4. **大纲到章纲是金字塔**：三幕式/救猫咪15节拍是骨架，卷纲（每卷20-30万字+独立主题+卷末钩子）→ 细纲（3000字章≤100字纲）→ 章纲（情节+人物+落点）层层细化。
5. **立意决定上限**：思想内核从"讲故事"升级到"现实观照"，融入家国情怀与传统文化是网文成为经典的关键，警惕低俗化侵蚀。
6. **可复用工作流**：题材卖点 → 梗概主线 → 人设 → 大纲/细纲/卷纲 → 开篇三章 → 书名/简介/标签包装，是一条完整的"爆款生产线"。
7. **反向学习法**：用AI拆书工具（如笔灵AI拆书）拆解成功作品的分卷结构和节拍节奏，比纯理论更高效。
8. **平台差异化**：8大平台书名/标签风格各异，投稿前务必研究目标平台的榜单风格，避免"一刀切"包装。
