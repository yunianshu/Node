## 一、女频写作技巧（女频爽点/套路）

| 要点 | 说明 |
|------|------|
| **黄金三章抓人** | 开头必须抓住读者：黄金三章、十章小高潮、三十章内大转折，学会卡点 |
| **大纲与人物小传** | 起好书名、简介，设置主要人物小传，建立完善的世界观与价值观 |
| **把握热门题材风向** | 先看自己擅长的类型，与热门题材相符更容易签约；多看同类型火书学习节奏 |
| **四大爽点类型** | 逆境反击、实力提升、打脸反转、情感满足（甜宠/双向奔赴/虐渣） |
| **情绪代入+节奏技巧** | 准确把握人物情绪让读者共鸣；用排比句增节奏、断句突出转折、短句强紧张感 |
| **爽点叙事弧线** | "被低估的主角→金手指→打脸"是爽文核心结构；欲扬先抑，爽点密集但不廉价 |

**脑洞组合法**：题材×元素矩阵法——左列热门题材（修仙/都市/末世/娱乐圈/历史）× 右列热门元素（系统/直播/签到/聊天群/国运/求生），随机连线挑出最意想不到但逻辑自洽的组合。

## 二、男频写作技巧（男频爽点/套路）

| 维度 | 核心要点 |
|------|---------|
| **爽点设计** | 期待感→爽点→情绪三位一体；掌握节奏，避免"写崩" |
| **经典套路** | 升级打怪、扮猪吃虎、装逼打脸、逆袭翻盘 |
| **句式技巧** | 短句断句增节奏感；排比句式强情绪；准确把握人物情绪 |
| **篇幅体量** | 男频主流作品篇幅通常 300-500 万字 |
| **作者同频** | 写完爽点/泪点后，要能判断读者能否感应到、是否与自己同频 |
| **平台格局** | "男起点女晋江"，起点中文网是男性读者主要聚集地 |

**进阶建议**：多读书、多分析，从作者角度看书，会发现很多好的脑洞方向和当下流行的内容；套路、爽点、剧情大致走向要先有方法论。

## 三、言情甜宠写法（高甜低虐/玻璃渣）

| 关键词 | 说明 |
|--------|------|
| **高甜低虐** | 以甜蜜互动为主线，虐点极轻或几乎无虐，保证读者愉悦体验 |
| **玻璃渣里找糖** | 适度加入冲突/误会制造张力，但迅速化解，虐少甜多 |
| **1V1 + HE** | 一对一专一感情线、大团圆结局是甜宠文标配 |
| **甜度密度** | 频繁投放高甜名场面（撒糖），保持"甜度密度"不掉线 |
| **经典CP搭配** | "霸总×软萌""偏执独宠""先婚后爱""暗恋""错撩"等模式 |
| **细分子流** | 暗恋流、错撩流、偏执独宠流、欢脱无虐流等 |

**实操建议**：先大量阅读榜单上的高甜甜宠文（知乎、豆瓣推荐书单），拆解其情节节奏与撒糖技巧，再结合 AI 辅助工具进行创作练习。

## 六、年代文写作技巧（70/80年代年代感）

| 技巧方向 | 具体做法 |
|---------|---------|
| **历史事件锚定** | 将故事节点对应到该年代大事件（1977恢复高考、改革开放、知青返城等） |
| **年代感营造** | 通过衣食住行、票证、流行语、社会风俗等细节还原时代质感 |
| **基层视角切入** | 用小人物、小切口反映大时代变迁（如《滨江警事》基层水警视角），增强代入感 |
| **考据支撑** | 援用翔实史料做扎实稽考，避免"穿越感"违和（考据流手法） |
| **叙事距离消弭** | 让当代读者产生情感共鸣，是年代文走红的核心策略 |
| **时代精神底色** | 70年代末至80年代是"反省与躁动"的新时期，需把握时代精神 |

**选题方向参考**：《2024 网络文学蓝皮书》提到年代文风行，更多作品采用基层人物视角、小切口表现新时代的写法。

## 本轮核心结论速记

1. **爽点共性公式**：无论男女频，爽文核心都是"被低估的主角→金手指→打脸/逆袭"的叙事弧线，配合欲扬先抑的节奏铺垫；女频偏情感满足（甜宠/虐渣/打脸），男频偏实力升级（升级打怪/装逼打脸）。
2. **甜宠三大铁律**：1V1 + HE + 高甜低虐；保持"甜度密度"不掉线，"玻璃渣里找糖"是制造张力又不劝退读者的关键。
3. **古言分层**：宫斗（后宫妃嫔）< 宅斗（家族利益）< 权谋朝争（朝堂百官），三者可层层升级；宅斗写到"地位"后常升级为宫斗。
4. **现言现实主义回归**：都市现言强调现实主义底色，选材立意+人物设定+主梗设计是三大基本功；总裁文→甜宠文→穿越文是范式演进主线。
5. **年代文四大支柱**：历史事件锚定 + 年代感细节 + 基层小切口 + 扎实考据；核心策略是"消弭叙事距离"，让当代读者产生共鸣。
6. **种田基建核心**：从无到有的经营成就感是最大爽点；金手指（现代知识/游戏系统）必须逻辑自洽；起点编辑青狐的种田题材细分是权威指南。
7. **大女主演变**：从"逆后宫/爱情至上"到"成为自己/事业为主"，女强文以杀伐果决、清醒独立的"狠"为核心关键词，题材已横跨古言/快穿/末世/赛博/玄幻。
8. **平台格局牢记**：男起点（男频 300-500 万字体量）、女晋江、起点女生网；番茄/阅文对现言甜文有具体品类要求，投稿前务必对标。
