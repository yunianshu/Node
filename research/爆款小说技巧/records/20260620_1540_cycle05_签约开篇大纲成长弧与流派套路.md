## 一、网文签约流程

### 起点中文网（三轮审稿机制）
1. **第一轮**：满6000字后编辑开始审稿
2. **第二轮**：未通过则编辑组交叉审稿
3. **第三轮**：仍未通过，满10万字后自己申请签约，编辑再审
- 门槛较高，付费阅读模式，订阅数据是关键

### 番茄小说（低门槛）
- 实名认证 + 6000字即可申请
- 合同签约人=账号实名认证人=银行卡归属人
- **对新人几乎不设签约门槛**，只要不触政策红线基本都能签
- 签作品不签人，版权属番茄，不能同时签第二家
- 免费阅读+广告分成模式

| 对比项 | 起点中文网 | 番茄小说 |
|--------|-----------|---------|
| 签约门槛 | 较高，三轮审稿 | 低，几乎不设门槛 |
| 盈利模式 | 付费阅读 | 免费阅读+广告分成 |
| 新人友好 | 一般 | 较友好 |
- 来源：知乎 https://zhuanlan.zhihu.com/p/1910378923440727331

## 二、前十章开篇节奏设计

### 通用节奏公式
```
第1章：开篇钩子 + 主角处境交代 → 章末悬念
第2-3章：核心冲突升级 → 第一个小高潮（爽点）
第4-5章：节奏稍缓，补充必要信息/人物关系
第6-7章：新矛盾引入，剧情加速
第8-9章：第一个大高潮铺垫
第10章：第一个小高潮爆发/反转 → 留大悬念
```

### 每章必备五要素
**核心目标 + 开篇钩子 + 核心冲突 + 爽点设计 + 章末悬念**

### 第一章"黄金第一章"技巧（马良）
- **用"邀请"代替"展示"**：邀请读者跟主角一起踏入未知
- **开篇钩子**：强有力悬念/冲突，让读者产生"然后呢？"
- **核心冲突前置**：不等几章才出冲突

### 开篇是"火折子"
"开篇就是故事的火折子，必须让它慢慢燃起来，让读者看到一丝光亮。"
- 来源：马良 https://maliangwriter.com/blog/novel-opening-chapter-techniques/

## 三、大纲模板（三幕式/救猫咪节拍表）

### 救猫咪15个节拍点
| 三幕 | 节拍点 |
|------|--------|
| **第一幕（建置）** | 开场画面 / 主题呈现 / 布局 / 触发事件 / 争执 |
| **第二幕（对抗）** | 进入第二幕 / 副线故事 / 乐趣与游戏 / 中点 / 坏人逼近 / 失去一切 / 灵魂黑夜 / 进入第三幕 |
| **第三幕（结局）** | 终局 / finale / 终场画面 |

### 其他大纲方法
- **"丰"字法**：一竖主线，三横（开始/过程/结局）
- **雪花法**：从一句话扩展到完整大纲
- **大树结构**：主线大纲（主干）→支线大纲（分枝）→细节完善

## 四、成长弧线设计

### 人物弧光（Character Arc）核心
指角色**心灵人格的变化**，不是简单"从弱到强"，而是内在认知/价值观/情感的转变。

### 弧线六要素
| 要素 | 说明 |
|------|------|
| **起点** | 初始信念、弱点或缺失 |
| **触发事件** | 打破原有世界观的契机 |
| **内在冲突** | 旧信念与新认知的拉扯 |
| **转折点** | 被迫做出选择的关键时刻 |
| **高潮（觉醒）** | 完成核心转变 |
| **终点（新状态）** | 以全新人格面对世界 |

### 弧线方向多元
不必"从弱到强"，可以是"从执念到释然""从自私到担当""从迷茫到坚定"。重点是让变化**可信、有层次、有代价**。
- 来源：知乎 https://www.zhihu.com/question/1993358028976718077

## 五、支线设计 / 多线叙事

### 七大技巧
| 技巧 | 说明 |
|------|------|
| **主线清晰** | 主线始终明确，支线是丰富而非干扰 |
| **POV视点法** | 不同角色视角交替推进（《冰与火之歌》） |
| **线索交汇** | 多支线在关键节点交汇，形成高潮 |
| **节奏控制** | 在读者遗忘前及时收束，避免"挖坑不填" |
| **角色驱动** | 让角色个性成为支线发展推动力 |
| **内在矛盾优先** | 多线中角色内在矛盾比外部冲突更吸引人 |
| **通俗切入点** | 无论多复杂，需浅显易懂入口代入 |

### 完整性原则
多线并列、插叙倒叙、打乱节奏都可以，但必须保证故事**完整性**——在读者完全忘记前面情节前将其组合成有意义的呼应。
- 来源：知乎 https://zhuanlan.zhihu.com/p/92491189 ; 机核 https://www.gcores.com/articles/98256

## 六、时间线管理（闪回/插叙）

### 三种事件顺序
- **顺叙与闪前**：正常顺序 / 提前叙述未来
- **倒叙与闪回**：结局提前 / 补叙过去
- **插叙与预叙**：中断主线补充背景

### 闪回实操（Reddit）
将内心独白与主题连接，用"十五年前"等过渡语自然切换时间线，再将闪回结尾与当前时间线衔接——感觉连续且相互关联。

### 关键原则
- **闪回应揭示角色核心动机**，需与上下文紧密结合
- 区分"故事时间"和"叙事时间"
- 可用可视化时间线工具辅助（如Lattics）
- 来源：三联生活周刊 https://www.lifeweek.com.cn/2013/0926/42609_3.shtml

## 七、长篇如何不崩盘

### 防崩盘五大维度
| 维度 | 方法 |
|------|------|
| **结构设计** | 主线+支线+细纲，分层管理（大树结构） |
| **视觉化** | 思维导图、画地图、"丰"字法、雪花法 |
| **设定管理** | 知识图谱、角色状态追踪、势力/背景设定表 |
| **分卷规划** | 三级大纲（总纲→分卷纲→章节纲）层层细化 |
| **连贯性维护** | 定期回看设定，建立设定集避免"吃书" |

### AI长篇连贯性维护（马良）
利用**知识图谱、三级大纲、角色状态追踪**三大工具，保持百万字级设定一致性。
- 来源：马良 https://maliangwriter.com/blog/ai-long-novel-consistency-guide/

## 九、章节标题取名技巧

### 五种取名方法
| 方法 | 说明 | 示例 |
|------|------|------|
| **事件概括法** | 核心事件命名 | "夜闯禁地" |
| **人物对白法** | 精彩台词 | "你配吗？" |
| **悬念暗示法** | 制造悬念 | "不速之客" |
| **情绪渲染法** | 情绪/氛围词 | "雨夜惊魂" |
| **诗词化用法** | 古风诗意 | "月落乌啼" |

### 关键原则
- **紧扣章节内容**，提取关键元素
- **巧妙暗示**而非剧透
- **简洁有力**，通常2-6字

### 重要提示
- **每章都取名字**，不留空不用"第X章"敷衍——好标题能让VIP订阅**直接翻倍**
- **擦边标题绝不过线**，涉及违规可能被处理
- 来源：知乎 https://zhuanlan.zhihu.com/p/370381041 ; 知乎 https://zhuanlan.zhihu.com/p/273559712

## 十一、系统流文（套路与创新）

### 系统流起源
源于2004-2006年网游文，"系统"从游戏系统泛化为通用金手指。

### 系统流子类型（按宿主互动方式）
- **任务流**
- **签到流**
- **升级流**
- **荣辱与共流**
- **幕后黑手流**

### 创新四大方向
1. 在套路框架内设计**差异化金手指**
2. 利用**短篇化**做叙事实验
3. **跨类型融合**（系统+无限流/悬疑等）
4. 对"系统"本质进行**反思性设定**

### 核心矛盾
读者需要套路的"安全感"，但又会厌倦重复——创新的关键是"在熟悉的框架里给意外"。

### 萌新友好
系统文是萌新最容易上手类型：①系统发布任务便于把控剧情主线；②有明确升级节奏。

## 十二、重生流套路

### 核心金手指：先知优势
重生文的"先知"比穿越文更强更实用——穿越文多为宏观历史事件，重生文可利用未来记忆（股市走向、商业风口、人际关系）精准操作。

### 六大套路
| 套路类型 | 核心写法 |
|---------|---------|
| **先知金手指** | 前世记忆，预知股市/风口/人际 |
| **商业逆袭** | 利用未来信息创业投资 |
| **感情补偿** | 弥补上辈子遗憾 |
| **复仇打脸** | 前世被害，重生后复仇 |
| **渣角从良** | 渣男/渣女重生改过 |
| **蝴蝶效应** | 改变小事件引发连锁反应 |

### "后类型化"创新
通过**反转套路**形成互文创新。
- 来源：搜狐 https://www.sohu.com/a/130966231_211467 ; 虎嗅 https://www.huxiu.com/article/384819.html

## 本轮核心结论速记

1. **签约**：起点三轮审稿(高门槛) vs 番茄6000字即申(低门槛)
2. **前十章公式**：每章必备"目标+钩子+冲突+爽点+章尾悬念"
3. **救猫咪15节拍**：三幕式建置→对抗→结局
4. **成长弧线**：六要素，方向多元(不必从弱到强)，要"可信有代价"
5. **多线**：POV视点法+线索交汇，内在矛盾比外部冲突更吸引人
6. **防崩盘**：知识图谱+三级大纲+角色状态追踪
7. **定价**：千字3-5分，长篇全本数百元引争议
8. **章节名**：好标题让VIP订阅翻倍，五种方法(事件/对白/悬念/情绪/诗词)
9. **2025趋势**：仙侠破世→创世，系统流跨类型融合，重生流蝴蝶效应创新
