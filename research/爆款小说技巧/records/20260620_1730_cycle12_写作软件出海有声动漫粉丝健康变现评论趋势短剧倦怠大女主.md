## 三、网文有声书改编

### 行业趋势
有声书成读者新选择，从平面到立体的阅读升级。中文广播剧从"为爱发电"发展为"声音经济"。

### 改编流程（再创作）
原著文本预处理 → 剧本编辑（拆分旁白/对话）→ 角色声线匹配 → 配音录制 → 配乐后期剪辑。**非简单有声化，是再创作**。

### 配音技巧
- **像平时说话一样**，与表演紧密结合
- 角色化声音处理、情感注入、多人协作分工

### AI制作工作流（2026）
文本预处理+角色提取 → 语音合成 → 后期处理。工具：讯飞智作、ElevenLabs、Ondoku。

## 七、网文写作变现路径

### 稿费收入（按千字/订阅分成）
- 典型分成：**作者30% / 平台70%**
- 计算示例：日更1万字+100人订阅，日稿费约20元；月更30万字仅约600元（扣税后）
- 全勤奖/签约奖金额外补贴

### 版权收入（核心高收入来源）
- 类型：影视/动漫/游戏/有声书改编
- 期限：一般5年左右
- 特征：头部作品版权可观，细水长流持续分成
- 写得好的小说仅稿费几十万，后续版权费持续分成

### 收入现状
| 层级 | 月收入 |
|------|--------|
| 签约平均 | 1000-2000元 |
| 全行业平均 | ~5133元（头部拉高） |
| 头部作家 | 数十万甚至更高 |
| 年入百万 | 多为版权收入贡献 |

### 关键认知
精品创作成趋势，大篇幅灌水不再提倡；版权收入才是真正高收入途径。

## 十一、网文日更崩溃 / 连载倦怠

### 日更高产方法论（第三阶段框架）
先搭建故事框架，包含：人物、地点、时间线、奖励、复仇、欲望、阻碍、升级、拉仇恨、反派、配角、失败两次、圈子、观众——避免中途卡文倦怠。

### 存稿缓冲机制
- 月初月底开文冲全勤
- 每章2050-2300字（利于有声+冲奖励）
- 每天码4000-8000字，正常发2000-6000，余下存稿
- 开书前几天日更4000-6000争取曝光

### 续写技巧六策略
| 策略 | 说明 |
|------|------|
| **搭建大纲框架** | 提前规划人物弧光、冲突升级、时间线 |
| **存稿缓冲** | 每日多码存稿备用 |
| **分阶段写作** | 开书冲量期→稳定期→收尾期 |
| **预设仇恨/悬念钩子** | 维持读者粘性和作者动力 |
| **配角支线轮换** | 切换视角、开新支线刷新新鲜感 |
| **冲榜节奏管理** | 配合平台活动调整更新量 |

## 十二、网文女主塑造 / 大女主文

### 大女主核心特征
不再刻意设定"女尊男卑"性别易位世界观，而是在相对现实/常规的男女社会结构中，让女主**凭自身能力、谋略、心性崛起**。

### 女强大佬型设定
从**人设上**给女主叠加各种技能点（生活/事业/武力），从设定层面立住"强"。

### 六大写法建议
| 维度 | 关键写法 |
|------|---------|
| **世界观** | 不必女尊男卑，常规社会靠能力突围 |
| **能力设定** | 多维技能点叠加（智商/武力/情商/事业），避免单薄 |
| **性格呈现** | 用具体行动代替标签；同情境下独特反应即人设 |
| **立体感** | 身份→外貌→性格层层细化，追求"活人感" |
| **开篇钩子** | 第一章暗示女主"超出预期"的秘密/能力 |
| **CP搭配** | "双强CP"当前热门，男女主势均力敌 |

### 网文人设7技巧（网文666）
用具体行动展示性格；同一场景不同性格差异化反应；普通社会身份+超出预期的秘密能力，第一章露端倪。
