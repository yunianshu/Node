## 四、网文版权法律 / 合同避坑

### 法律基础
《著作权法》——人身权（署名权、保护作品完整权）+ 财产权（改编权、信息网络传播权）。

### 阅文合同争议
旧合同要求作品独家授权期限为**整个著作权保护期**（作者生前+死后50年），引发作者广泛不满。2020年新版合同明确：作品是否加免费由作者确认，人身权归作者，平台与作家是"合作"非"聘请"。

### 七大合同避坑
| 要点 | 说明 |
|------|------|
| **授权期限** | 警惕"永久授权"/"整个著作权保护期"，争取有期限 |
| **权利类型** | 区分"独家许可"vs"版权转让"，转让=绝卖 |
| **人身权归属** | 署名权等始终归作者 |
| **免费阅读** | 是否加免费由作者知情同意 |
| **收益分成** | 关注IP改编/影视化衍生收益分成 |
| **合同性质** | 明确"合作"还是"聘请" |
| **证据保留** | 创作过程/沟通记录/版权登记证书 |

### 海外版权
对欧盟、东盟、美国版权立法梳理，为网文出海提供对策。
- 来源：著作权法 https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html ; 南都 https://m.mp.oeeee.com/a/BAAFRD000020200628339124.html

## 五、《诡秘之主》创作拆解（爱潜水的乌贼）

### 核心创作思路
**"我先设定世界观，再考虑怎么升级"**——世界观构建优先。

### 象征性叙事手法（有意设置）
"希望把不便于直接阐述的东西，通过象征性叙述让读者自己去挖掘"——理解其文本暗线的钥匙。

### 元素融合（非简单堆砌）
不是简单堆砌克苏鲁与蒸汽朋克，而是通过**精妙叙事技巧**将二者有机糅合进完整社会架构。

### 连载互动
与读者"斗智斗勇"的互动过程成为写作动力。

### 完结九大关键词
作者本人在完结感言中亲自总结——第一手、最权威的写作经验。

## 六、《斗破苍穹》创作拆解（天蚕土豆）

### 核心公式
**"复仇+以下克上+金手指+热血战斗场面"**，商业性极强。

### 角色塑造秘诀（复旦分享）
为笔下角色设定**"目标感"**：通过情节推动角色成长，赋予性格与能力特质（如萧炎）。

### 套路化写作开创
在天蚕土豆之前，还没有网文作者如此娴熟地使用"套路"来写作，这一写法至今长盛不衰。

### 风格定位
**"少年、热血、励志"**，《斗破苍穹》是写给当时的自己。

### 多作品联动
构建萧炎、林动等角色共存的"大千世界"体系（《斗破》→《武动乾坤》→《大主宰》）。

### 断更与灵感
长篇创作会遇到灵感枯竭，这是创作者无法回避的瓶颈。

## 七、三幕式 / 英雄之旅 / 节拍

### 理论谱系
坎贝尔《千面英雄》（17阶段）→ 沃格勒《作家之旅》（12阶段简化）→ 斯奈德《救猫咪》（15个节拍表）。

### 三幕对应英雄之旅
- **第一幕（启程）**：日常世界→冒险召唤→拒绝召唤→导师→跨越门槛
- **第二幕（启蒙）**：考验/盟友/敌人→接近深处洞穴→严峻考验→得到奖赏
- **第三幕（归返）**：归返之路→复活→带仙丹凯旋

### 网文应用注意
长篇网文可能不适合生搬三幕式，需结合升级流、多卷制进行结构扩展。B站有"小说三幕式结构如何写细纲""九线拆分法"等实战教程。

## 八、网文主角人设公式

### 完整人设模板七模块
| 维度 | 内容 |
|------|------|
| **基础信息** | 姓名、年龄、外貌、身份背景 |
| **性格特征** | 核心性格+反差性格（制造记忆点） |
| **核心动机** | 目标/欲望（推动剧情引擎） |
| **标志性元素** | 口头禅、特殊习惯、标志性外貌 |
| **关系网络** | 朋友、敌人、导师、情感线 |
| **成长弧线** | 从起点到终点的变化路径 |
| **社会背景** | 世界观、阵营、阶层 |

### 三大加分要素
**一个标志性特征 + 一句口头禅 + 一次破例行为**能迅速为角色加分。

### 人设三维度（七猫）
生理特征、主观心理、社会背景。

### 人设概念（中国作家网）
先构思人物性格/气质/行为模式模板，再形成具体形象——"席勒化"人物观。

## 九、反派智商设计

### 六大设计要点
| 要点 | 说明 |
|------|------|
| **不降智** | 反派计谋不幼稚，避免为衬托主角强行让反派犯错 |
| **内心能量** | 必须有"强者心态"和自我认同 |
| **逻辑自洽** | 每一步行动有合理动机和缜密计划 |
| **见微知著** | 高智商=线索不是角色找的，而是从细节推导的 |
| **平台适配** | 不同平台读者偏好不同 |
| **伏笔铺垫** | 优秀反派计谋需前置伏笔，让读者事后恍然大悟 |

### 平台反派写法差异（网文666）
- **起点**：理念碰撞
- **番茄**：情绪爆发
- **飞卢**：命运错位
- **晋江**：情感撕扯
- **纵横**：格局高下

### "如何写出比自己聪明很多的角色"难题
需多读多积累，有想法才能创造。

## 十、打脸情节设计

### 打脸本质
反派嘲讽/轻视→主角实力反转→狠狠打脸。**打脸的轻重程度直接决定读者爽感强弱**。

### 节奏控制（平台差异）
- **飞卢式**：3章一个完整打脸周期，一天爽两三回
- **晋江式**：含蓄式，"用实力让你无话可说"的暗爽

### 升级手段
从单纯实力碾压 → 反套路完成任务 → **情感+实力双重打脸**。

### 经典场景
拍卖会打脸（主角灵石多、使劲砸、打脸公子哥）。

### 海外影响
海外原创小说也在学习中国网文"升级打脸"，弱小主角逐渐变强站起来反击。
- 来源：知乎 https://zhuanlan.zhihu.com/p/567191558 ; 豆瓣 https://m.douban.com/group/topic/486863318/

## 十一、金句台词 / 名场面设计

### 网络金句特征
雅俗共赏、兼具趣味性与深刻性、多来源于名著名言、自带格调、富有强感染力、为情绪表达提供载体。

### 名场面的结构作用
**"网文名场面更接近于整本书的'锚点'"**——长篇网文若缺少锚点定住风格，"越写越飘"。

### 名场面感染力来源
从读者反馈视角反推：读后感、配音、考卷等花式玩法，超5万书粉投稿"我与名场面的故事"。

### 台词语感积累
B站"网络小说经典名句"视频合集可作素材。

## 十二、追读率 / 章节留存数据优化

### Cohort同期群分析应用
按读者"入坑章节"分群，对比追读衰减曲线——定位"弃书章节"优化剧情节奏。

### 章节留存映射
通用留存的"次留/七留/月留" → 网文"**章节留存**：第N章→第N+1章的追读率"。

### 行为相关性
通用"Session长度 vs 留存" → 网文"**单章阅读时长 vs 追读意愿**"。

### 流失节点定位
通用"找到用户流失的步骤" → 网文"定位弃书章节，优化剧情节奏"。

### 五大分析维度
| 维度 | 网文场景应用 |
|------|------------|
| 同期群分析 | 按入坑章节分群对比追读衰减 |
| 留存率计算 | 章节留存：N→N+1追读率 |
| 流失节点定位 | 定位弃书章节优化节奏 |
| 行为相关性 | 单章阅读时长vs追读意愿 |
| 推荐优化 | 章节/书单推荐对追读率影响 |

## 本轮核心结论速记

1. **行业**：5.75亿用户，阅文新增白金大神90后超70%，番茄3-5年达50亿稿费
2. **读者**：年轻化+性别均衡+偏好分化+代际融合，男玄幻/女言情
3. **短剧**：长剧短剧化短剧精品化，避免群像聚焦主线，拆解爆款是关键
4. **版权**：警惕永久授权/版权转让=绝卖，人身权始终归作者，保留维权证据
5. **诡秘**：世界观优先+象征性叙事+元素有机糅合+连载互动
6. **斗破**：复仇+以下克上+金手指+热血，目标感驱动，套路化写作开创者
7. **结构**：坎贝尔→沃格勒→斯奈德谱系，长篇网文需扩展不生搬
8. **人设**：7模块模板，标志特征+口头禅+破例行为三加分
9. **反派**：不降智+逻辑自洽+见微知著+平台适配，5平台写法各异
10. **打脸**：轻重定爽感，飞卢3章周期vs晋江含蓄暗爽，情感+实力双重打脸
11. **名场面**：是全书"锚点"定住风格，防止"越写越飘"
12. **追读**：Cohort分析定位弃书章节，单章阅读时长vs追读意愿
