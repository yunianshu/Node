## 一、无敌流 / 龙傲天

### 六大技巧
| 技巧 | 说明 |
|------|------|
| **开局即无敌/满级** | 直接给最强实力，以"碾压"为核心爽点 |
| **装弱→碾压反转** | 最常见写法，隐藏实力制造反差爽感 |
| **赋予朴素动机** | 超强力量+朴素生存/目标动机，避免空洞龙傲天 |
| **多重身份/系统金手指** | 让无敌"合理化"，增加看点层次 |
| **信息差碾压** | 跨世界知识降维打击（地球作品在异世界） |
| **节奏把控** | 长篇易"越写越水"，注意新鲜感维持 |

### 经典写法
"无敌流有很多种写法"，最常见是"装弱→碾压"。

## 二、诸天流 / 诸天万界

### 结构设计
单元剧形式，每个世界一个相对独立故事，但需埋设长线主线。

### 长线布局能力（核心）
优秀无限流/诸天流，中后期会在短线位面故事中嵌入**长线主线线索和目标**，甚至从开篇几个位面任务就开始铺设。

### 开头吸引力
独特的穿越设定 + 强烈的冲突悬念 + 奇特情境下获得穿梭诸天能力。

### 短线vs长线
- 短线：每个位面独立故事
- 长线：贯穿全程的终极目标和线索
- 来源：飞书 https://docs.feishu.cn/v/wiki/VOazwHo1Bi7d3Lk3GGxc0uunnYe/ak ; 知乎 https://zhuanlan.zhihu.com/p/343593032

## 三、签到流 / 签到系统文

### 核心逻辑
**降低作者写作成本 + 降低读者阅读成本**，将升级体系流程化、无脑化。

### 五大爽点
| 爽点 | 说明 |
|------|------|
| **短线期待感** | "这次签到会得到什么"持续悬念，类似开盲盒 |
| **耐心回报感** | 长时间签到必有丰厚收获，积累型快感 |
| **打脸反转** | 低调签到积累后关键时刻爆发 |
| **无敌碾压** | 签到奖励往往直接顶级（至尊骨、混沌体） |
| **轻松休闲** | 节奏快、爽点多、门槛低 |

### 签到地点设计
宗门后山→至尊骨；老祖坟头→上古功法；城市→豪车豪宅；绝地禁地→高级奖励。

### 流程化写作闭环
签到→获奖励→新实力→新冲突→新场景→新签到（可持续输出）。

### 奖励梯度
早期解决生存 → 中期提升实力 → 后期涉及世界观核心秘密。

## 四、模拟器流

### 核心爽点
体验不同人生、预知未来逆天改命、通过模拟反复试错获取最优解。

### 五大写作要点
1. **模拟与现实关系处理**：平衡双线比例，避免说明文字过多行文干瘪
2. **避免套路重复**：每次模拟注入新变数，而非单纯重复
3. **构建环环相扣情节链**：遵循起承转合
4. **借鉴签到流+无限流优点**：融入无限流悬念感、挑战性，有向上挑战动机
5. **题材跟进与创新**：关注天榜/新书榜，跟潮流同时找独特切入

### 核心魅力
**"试错"与"重来"带来的信息差爽感**。

## 六、赘婿战神 / 神医文

### 核心引擎：信息差
隐藏身份 → 被嘲讽/羞辱 → 身份揭露 → 打脸反转。

### 多身份融合趋势
战神+奶爸、神医+奶爸、神医+赘婿；身份元素：神医、弃少、兵王、战神、仙帝、风水师、龙王。

### 开篇切入场景
监狱流、机场回归流、神医下山流。

### 写法特点
- 多以**第一人称**为主，开篇讲述婚姻矛盾处境
- 利用隐藏身份制造信息差，形成持续悬念期待
- **打脸节奏**：小打脸→中打脸→大打脸层层递进

### 大纲先行
多身份叠加需严密大纲保证逻辑自洽。

## 七、纯爱 / BL耽美 / 双男主

### 双男主人设（飞书万字Prompt）
两个男主都应是"世界之王"，但绝不在同一领域；或一个已是世界之王，另一个是"要成为世界之王的王"。

### 淮上创作心得
尽量不代入个人视角，写自己喜欢、想写的，不把自身择偶观代入角色。

### BL与BG结构
除主角性别配对外，很多写法可互相转换。

### 技巧参考
借鉴金庸武侠分析节奏把控，深入探讨"高潮点"营造。

**表白前的暧昧期**、双向暗恋的心理描写。

### 视角选择
要先决定以"攻"视角还是"受"视角叙事，双向暗恋重点在心理刻画。

### 六大要素
| 要素 | 建议 |
|------|------|
| **核心看点** | 表白前暧昧、双向暗恋心理 |
| **视角选择** | 确定攻/受视角深入内心 |
| **人物塑造** | 通过反应展示性格 |
| **情节结构** | 提前搭建大纲，设悬念伏笔 |

| **素材积累** | 多读优秀GL作品 |

## 九、治愈系 / 救赎文

### 经典模式

**"兜底的安全感"**——让读者/角色感受到被接纳、被理解。

### 五大要素
| 要素 | 要点 |

| **实操方法** | 大纲→人物关系→场景→叙述视角 |

## 十、破镜重圆 / 重逢文

### 两种经典写法（晋江论坛）
1. **顺序写法**：重逢→大篇幅回忆→先写"破"再写"圆"
2. **插叙写法**：先重逢，分手过程用插叙逐步揭露

### 开篇重逢难点
开篇即重逢若全是情节，容易显得感情不到位——需平衡剧情描写与情感渲染。

### 分手合理性
**分手时角色年龄越小**（如18岁或更小），误解和沟通不畅更易用"年轻缺乏经验"解释，读者接受度更高。

### 避免套路
不要用"苦等/深情"硬圆，逻辑要自洽。

### 核心看点
久别重逢后的**追与躲**拉扯感。

## 十一、养成文 / 年下

### 核心写法
养成系写法接近**种田文**，强调日常细节、温馨氛围、陪伴成长。"发展主线就是主角养成徒弟，可借鉴种田文。"

### 四大要点
| 要点 | 说明 |
|------|------|
| **核心写法** | 接近种田文，日常细节、温馨氛围、陪伴成长 |
| **情感递进** | 年下设定中：依赖→独立→情感转变的成长弧线 |
| **年龄差处理** | 合理把握心理差异与权力关系变化 |
| **参考类型** | 双男主文、玄幻养成徒弟、古言养成甜文 |

### 经典元素
年龄差、青梅竹马、温馨日常。
- 来源：爱Pia戏 https://aipiaxi.com/article-detail/633981 ; 知乎专栏 https://zhuanlan.zhihu.com/p/713727514

## 本轮核心结论速记

1. **无敌流**：开局满级/装弱碾压，赋予朴素动机避免空洞
2. **诸天流**：单元剧+长线主线，长线布局能力是关键
3. **签到流**：流程化写作闭环，开盲盒期待感+打脸反转
4. **模拟器流**："试错重来"信息差爽感，避免套路重复
5. **抽卡流**：收集癖心理+欧皇非酋代入感
6. **赘婿战神**：信息差是核心引擎，打脸层层递进，大纲先行
7. **纯爱BL**：双男主都应是不同领域"世界之王"
8. **百合GL**：表白前暧昧+双向暗恋心理是核心看点
9. **治愈救赎**："兜底的安全感"内核，压抑→试探→双向救赎
10. **破镜重圆**：顺序/插叙两种写法，年少分手更易接受，追与躲拉扯感
11. **养成年下**：接近种田文，日常温馨+陪伴成长弧线
