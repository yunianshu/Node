## 一、凡人流（《凡人修仙传》开创）

### 流派核心
主角凭**智慧、努力与少量运气**获成功，而非天赋异禀。以**资源争夺、缓慢升级**为核心的大长篇、慢热修仙。

### 忘语写作方法论
1. **提前3年构架世界观**，后期再细化丰满，加入临时灵感
2. **代入式写作**：读者强代入感是凡人流最核心阅读体验
3. **类似上班的写作纪律**：用毅力和天赋让创作持续
4. **合理化脑洞**：设定可天马行空，但必须逻辑自洽

### 四大艺术手法
- **对比手法**：不断运用资质/天赋对比，突显主角的平凡与艰难
- **非传统爽文**：不追求即时快感，受中年骨灰级读者喜爱
- **慢热升级**：主角一步一个脚印
- **故事框架庞大精密，情节跌宕起伏**

## 二、洪荒流（《佛本是道》开山）

### 核心设定
以中国神话与古代神魔小说为蓝本：**大道、天数、因果、业力、无量量劫**。

### 时间线体系
混沌初开 → 天地诞生 → 龙汉初劫 → 封神 → 西游

### 写作五大要点
1. **吃透原典**：熟悉《封神演义》《西游记》《山海经》及道教神话，分清原典vs网文设定
2. **构架完整世界观**：修炼境界（准圣/圣人/天道）、势力划分（三清、女娲、西方二圣）
3. **把握流派核心**：天数、因果业力、量劫、圣人博弈
4. **写好大纲**：横跨多量劫、多势力，没大纲极易崩盘
5. **势力博弈写法**：三清矛盾、西方二圣从三清道统"偷人"的算计
- 来源：17K https://author.17k.com/ck/author/article/content/43.html ; 搜狐 https://www.sohu.com/a/591141787_100213690

## 三、漫威/美漫同人

### 关键技巧
1. **自建宇宙（AU）**：原著时间线庞杂，自建平行宇宙避免设定冲突
2. **大量阅读积累**：写之前至少阅读百篇同类
3. **善用叙事枢纽**：如"跨维度日记簿"构建现实与漫威世界联系
4. **熟悉两大IP体系**：漫威+DC核心角色、大事件、力量体系
5. **题材创新**：网游版美漫、幕后流等同质化中找差异

## 四、火影/动漫同人

### 火影适合写同人的原因
- 丰富的**世界观构建**
- 大量角色和人物塑造空间
- 很多 **"如果"理论**可发挥
- 力量等级体系（忍术）有延展性

### 同人创作核心
| 技巧 | 说明 |
|------|------|
| **世界观还原** | 最基本要求是遵循原作设定再合理延伸 |
| **角色把控** | 避免OOC（角色崩坏），保持性格一致 |
| **"如果"思维** | 利用原作空白点合理想象假设 |
| **力量体系** | 忍术体系是好创作素材，可扩展但需自洽 |
| **戏剧张力** | 虐文/高潮需把控节奏和情感冲突 |
| **多读多练** | 阅读高质量同人是提升有效途径 |
- 来源：Reddit r/NarutoFanfiction ; 巴哈姆特 https://home.gamer.com.tw/artwork.php?sn=2684924

### 写同人是好的写作练习
提升：拼写语法、情节构建、人物弧光规划、"展示而非讲述"、语调氛围营造。

## 五、海贼王同人 / 综漫

### 叙事模式
- **跟船流**：跟随路飞冒险
- **非跟船流**：独立支线（如《海贼王之萝莉养成系统》）
- 综漫通常采用**穿越+系统设定**融合多部作品

### 五大技巧
1. 掌握原作世界观（恶魔果实、霸气、世界政府架构）
2. 选择叙事模式
3. 先写大纲再拆章节，避免剧情崩坏
4. 多读优秀同人学习人物塑造/剧情节奏/爽点
5. **注意综漫力量平衡**，合理设定战力体系避免失衡
- 来源：知乎 https://www.zhihu.com/question/277047375 ; 百度百科《海贼王之萝莉养成系统》

## 六、快穿文

### 与一般长篇不同
需要设计**多个不同世界**，进行剧情设计和内容填充。

### 主题方向
逆天改命、女性意识觉醒、反恋爱脑、反主角光环、自我救赎等。

位面故事的设定逻辑与内容填充经验。

### 常见问题

## 七、古言经商 / 女经商文

### 核心理念（意千重）
事业线（经商线）必须与故事情节**相契合**，要成为助力而非拖累；要让主角和故事**脱颖而出——有趣、特别、有辨识度**。

### 古言分支定位
种田经商文、宫斗宅斗文、权谋朝争文、江湖文。

### 创作顺序建议
1. 先读事业线设定 + 古言分支定位——解决"经商线怎么融入故事"
2. 场景描写——古代市井氛围笔感
3. 爽点设计——打脸、逆袭、商战冲突爽感节奏
4. 投稿平台和题材风向判断

### 大女主精神内核
聚焦女性**性格、命运、成长经历与独立人格的形成**。

## 九、警匪悬疑 / 刑侦文

### 分类
- **侦探小说**：围绕侦探调查谋杀案（《福尔摩斯》）
- **刑侦小说**：以警察为主人公，侧重公安系统侦破过程

### 侦探小说创作原则
- 作者与读者**平等对待**，保证信息对称
- **逻辑推理**是核心，情节必须合理
- 聚焦智力竞赛，避免无关情感和超自然元素

### 悬疑构建套路
先设定**死亡事件** → 添加让事件**复杂的细节** → 添加**破案线索细节** → 层层递进。

### "悬"与"疑"
"悬"是悬念，"疑"是怀疑。悬疑小说以解决悬念、探索未知为主要驱动力。
- 来源：知乎 https://zhuanlan.zhihu.com/p/685057344 ; Scribd https://www.scribd.com/document/851338279/

## 十、女频宅斗 / 婆媳 / 嫡女文

### 宅斗多维度争斗
妻妾争斗、姐妹争斗（嫡女vs庶女）、妯娌争斗、婆媳争斗、朝堂斗争。

### 经典模式
庶女逆袭 → 得嫁高门 → 勇斗妾室 → 成为当家主母 → 商业独当一面。

### 嫡女文技巧
- 采用**第三人称有限视角**，跟随主角展开
- **重生设定**：让读者有"上帝视角"快感，期待女主用前世经验反击
- 重点刻画女主**心理变化**过程

### 五大创作核心
1. **多维度冲突**：婆媳+姐妹+妻妾+妯娌交织
2. **身份差异化**：嫡庶、正侧制造天然矛盾
3. **重生/穿越设定**：先知优势制造爽感反转
4. **情感共鸣**：权谋中嵌真情
5. **由小及大**：宅院内斗延伸到政斗，层次分明

### 经典代表
《庶女攻略》（吱吱·开山）、《嫡谋》、《闺宁》、《嫡女宅斗指南》。
- 来源：宅斗文百度百科 https://baike.baidu.com/item/%E5%AE%85%E6%96%97%E6%96%87/1439589 ; 知乎 https://zhuanlan.zhihu.com/p/72252851

## 十一、年代文（70/80年代）

### 核心技巧
1. **吃透时代大事件**：1977恢复高考、改革开放、知青返城，情节与历史节点对应
2. **还原生活细节**：服饰（的确良、中山装）、食物（粮票油票）、交通（自行车绿皮火车）、用语（时代口号）
3. **把握时代精神底色**：70年代压抑期盼、80年代启蒙反思躁动奋进
4. **塑造符合年代的人物**：思想观念行为逻辑符合当时社会环境
5. **参考真实史料**：避免年代穿帮

### 70年代素材
的确良白衬衫、蓝粗布裤子、唱"我们是共产主义接班人"。

### 80年代特征
文学进入"新时期"，在反省和躁动中发展。有"两个80年代"——改革/启蒙/现代化（反思基调）vs 不同面向。

## 本轮核心结论速记

1. **凡人流**：忘语提前3年构架世界观，对比手法+代入感+合理化脑洞
2. **洪荒流**：天数/因果/量劫/圣人博弈是灵魂，必须写大纲防崩盘
3. **美漫同人**：自建AU宇宙避免设定冲突，至少读百篇同类
4. **火影/综漫**：避免OOC，"如果"思维扩展，综漫注意力量平衡
5. **快穿**：多世界设计，避免位面感情同质化
6. **古言经商**：事业线相契合+有趣有辨识度+大女主独立人格
7. **军旅**：亲身经验为底图，AB面多重性，英雄主义内核
8. **刑侦**：信息对等+逻辑推理，死亡事件→复杂细节→线索递进
9. **宅斗**：多维度冲突（婆媳/姐妹/妻妾/妯娌），重生设定+由小及大
10. **年代文**：吃透大事件+还原生活细节+符合年代精神
