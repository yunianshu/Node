## 一、单章结构模板（每章写什么/章节节奏）

| 要点 | 说明 |
|------|------|
| **章节钩子设计** | 每章开头与结尾设置"钩子"（悬念/反转/新信息），结尾留悬念保证追读率，是节奏控制的第一抓手。 |
| **爽点密度规划** | 单章内必须有可量化的爽点/情绪点，建议每章至少 1 个明确情绪峰值，避免"水章"。 |
| **三段式单章结构** | 常见模板：开场（承接上章悬念/抛出新冲突）→ 转折（推进/反转）→ 结尾钩子（抛新悬念收尾），对应"开场-转折-结尾"蓝图拆分法。 |
| **情绪曲线管理** | 单章情绪不能一条直线，需有起伏；连续几章累计情绪后再爆发，形成"压抑—释放"的脉冲。 |
| **滚动存稿缓冲** | 用 5-10 章滚动存稿调整节奏，避免断更压力下硬写垃圾章，保证章质量稳定。 |
| **三阶段情节系统** | 微观层做章节填充与节奏控制，配合中观"细纲"与宏观"卷纲"，逐层落地节奏。 |

## 二、卷纲设计（分卷规划/每卷高潮）

| 要点 | 说明 |
|------|------|
| **分卷依据** | 按情节发展阶段 / 地图变换 / 核心矛盾切换来切卷，每卷有独立主题、目标和核心矛盾，并明确本卷的起止标志。 |
| **三层大纲法** | 总纲（全书鸟瞰）→ 分卷纲（补每卷目标、冲突、卷末钩子）→ 章纲（逐章蓝图），由粗到细落地。 |
| **卷纲文件结构** | 每卷可独立成文件，写明：卷名 + 字数 + 章数 + 核心事件 + 状态变化 + 爽点节奏 + 情绪弧线 + 人物弧线 + 伏笔 + 反转。 |
| **高潮设计** | 每卷需有一个核心高潮事件（主爽点），通常放在卷中偏后或卷末，作为本卷的情绪峰值。 |
| **卷末钩子** | 高潮后必须留悬念/反转引出下一卷，避免卷与卷之间出现"断崖式掉追读"。 |
| **起承转合粗纲** | 用"起承转合"概括全卷大纲，再让细纲紧密贴合粗纲，确保每段情节"有作用"（为高潮铺垫/解释因果），砍掉无用情节。 |

## 三、主线支线设计（多线交织/交汇点）

| 要点 | 说明 |
|------|------|
| **主线多线系统法** | 以主线为骨架，挂载 1-3 条副线，避免支线喧宾夺主；新手优先单线，单线≠平铺直叙，关键在情节密度与冲突。 |
| **交汇点设计** | 多线必须在预设的"交汇点"收束，否则剧情散乱；交汇点是副线与主线交叉的关键节点，决定多线是否成网。 |
| **表格法管理多线** | 用表格 B 列列副线，主线为主轴，副线交叉点对齐到主线时间轴，用空白单元格体现副线的断续性，可视化追踪。 |
| **主线优先级** | 设置主线后要不断强化主线，砍掉不必要的铺垫和旁枝末节，简洁直接扣住主线推进。 |
| **篇幅控制** | 多线交织的扩展/精简极限约在 30 万字，超出容易臃肿，长篇需适时收线或并线。 |
| **双线结构类型** | 双线可平行、一明一暗、或交叉，用于丰富内容、埋暗线，暗线在后期揭示产生惊喜。 |

## 四、副本设计（副本流/单元剧结构）

| 要点 | 说明 |
|------|------|
| **主线+单元结构** | 每个副本/世界是独立小故事，主线线索贯穿所有副本；主角每通一个副本获得一个线索，最终拼出完整真相。 |
| **单元剧优势** | 与短视频时代天然契合，节奏明快、阅读门槛低，可包容任意 IP/时代/风格，作者写作灵活度高。 |
| **副本设计要素** | 主题内核一致、虚实场景融合、规则与叙事结合、逻辑严丝合缝的闭环；需兼顾新颖刺激与日常感。 |
| **副本间联系** | 通过线索递进、角色成长、伏笔回收处理单元之间的关联，避免副本像散落的"闯关舞台"。 |
| **破局同质化** | 把副本融入社会议题、现实映射与人性思考，避免干巴巴的规则堆砌；创新规则与叙事的结合方式。 |
| **规则与人性矛盾** | 优质副本常让"系统规则"与"人性抉择"形成矛盾，贯穿主线，强化悬疑与张力。 |

## 五、地图换地图升级（换地图节奏/新场景设计）

| 要点 | 说明 |
|------|------|
| **旧地图完整收束** | 换地图前，旧地图的伏笔要回收、战力要展示到位，给读者"阶段性满足感"，再开启新地图。 |
| **过渡要自然** | 旧地图收尾 → 过渡章 → 新地图展开，换地图不能突兀，要有铺垫和逻辑过渡，避免读者割裂感。 |
| **威胁等级跃升** | 新地图的威胁等级要明显高于旧地图，制造"降维打击"压力，推动主角新一轮升级，维持升级感。 |
| **差异化场景设计** | 新场景要在地理、文化、势力体系上做差异化，给读者新鲜感；为新地图设计独立的标志性事件。 |
| **节奏多节拍** | 借鉴游戏关卡设计：分开设计多个节拍再组合，新场景要有层次和转折，避免笔直无变化的"道路"让读者无聊。 |
| **爽点重新积累** | 新地图前期适当压抑，中期爆发，重新积累爽点密度，避免延续旧地图的审美疲劳。 |

## 六、三幕式 / 救猫咪节拍 / 英雄之旅应用

| 要点 | 说明 |
|------|------|
| **三幕式搭骨架** | 开始→中间→结尾的宏观结构，适合规划全书"起承转合"，是最灵活、最不易焦虑的框架。 |
| **救猫咪15节拍** | 第一幕（建置）：开场画面、主题呈现、铺陈设置、触发事件等；把每卷/大事件按15节拍拆分节奏，精细化填充。 |
| **英雄之旅12阶段** | 坎贝尔《千面英雄》→沃格勒《作家之旅》→斯奈德《救猫咪》→菲尔德三幕式，一脉相承；英雄弧线特别适合主角成长线/升级流网文。 |
| **三者嵌套使用** | 三幕式搭骨架 → 英雄之旅规划主角成长弧 → 救猫咪节拍填充每一幕关键情节点，三者互补不互斥。 |
| **"救猫咪"技巧** | 让主角早期做一件善事赢得读者好感，是建立主角讨喜度的经典手法，可移植到网文开篇。 |
| **灵活优先** | 过度追求节拍的精确位置反而焦虑，新手建议以三幕式为主、节拍表为辅，按需取用。 |

## 七、冲突设计（内在冲突/外在冲突/矛盾驱动）

| 要点 | 说明 |
|------|------|
| **外在冲突** | 角色与外部世界（社会、他人、自然）的对抗；网文中常变现为竞争比赛、打破规则、势力对抗。 |
| **内在冲突** | 角色内心的情感、价值观、欲望之间的挣扎；常见套路：角色无法接纳自身缺陷、感性与理性的拉扯、习惯性逃避。 |
| **矛盾是发动机** | 矛盾冲突是驱动情节前进、塑造人物弧光的"熔炉"，不应是硬加的佐料，而要自然推动情节。 |
| **五类矛盾** | 竞争与比赛、内心意愿与理想、打破规则、价值观差异、因果关系——任选其一或组合作为冲突源。 |
| **核心原则** | "别让主角成长得太顺了"——情理之中意料之外的冲突，靠前期铺垫让爆发有说服力。 |
| **逆向梳理法** | 以玄幻为例，先定终点（如生死搏杀）再倒推前置环节（拍卖会→伏击→生死搏杀），让冲突链条完整。 |

## 八、危机设计（危机升级/绝境反击）

| 要点 | 说明 |
|------|------|
| **危机设计模板** | 典型设计：主角团队面临前所未有危机，可能导致伙伴牺牲、功力尽失或信念动摇，为后续绝地反击和人物成长铺垫。 |
| **先抑后扬（延迟满足）** | 避免上来就打脸，先制造危机/压抑，积累情绪后再反击爆发，把平淡胜负转化为具体情感爆发。 |
| **冲突升级** | 危机要层层递进、不断加码，每一层比上一层更紧迫、代价更大，形成"危机阶梯"推高张力。 |
| **绝境反击节奏** | 反击前主角应处于真正的绝境（无路可退），反击爆发点要卡在情绪最压抑之后，落差越大爽感越强。 |
| **升级循环** | "危机—升级—突破"叙事循环：危机驱动主角升级，突破后解决危机，再进入下一轮更大危机，形成可持续爽点。 |
| **控制感与心流** | 借鉴游戏的"控制感"心流机制——危机让读者紧张，突破让读者获得掌控感，反复循环维持追读。 |

## 本轮核心结论速记

1. **结构是分层的**：单章（钩子-转折-结尾）→ 卷纲（目标-冲突-卷末钩子）→ 全书（三幕/英雄之旅），每一层都有可复用的模板，由细到粗互相对应。
2. **节奏的本质是脉冲**：无论单章、单卷还是换地图，核心都是"压抑—释放—再压抑—大爆发"的情绪曲线，爽点密度必须可量化，避免水章。
3. **多线靠交汇点成网**：主线挂副线不可怕，可怕的是没有预设交汇点；用表格法把副线交叉点对齐主线时间轴，是防止剧情散乱的最实操工具。
4. **副本流是单元剧+主线线索**：每个副本独立成章，靠"线索递进/角色成长/伏笔回收"串联，破同质化的关键是融入人性思考而非堆规则。
5. **换地图三步走**：旧地图完整收束 → 自然过渡 → 新地图威胁跃升+爽点重积累，借鉴游戏关卡的多节拍设计。
6. **三大框架嵌套用**：三幕式搭骨架、英雄之旅画主角弧、救猫咪15节拍填关键点；新手以三幕式为主，节拍表为辅，别为节拍位置焦虑。
7. **冲突是发动机**：外在冲突+内在冲突双驱动，五类矛盾源任选组合，核心是"别让主角太顺"，逆向梳理法保证冲突链条完整。
8. **危机=延迟满足的放大器**：先抑后扬、危机阶梯升级、绝境卡在情绪最压抑后爆发，配合"危机—升级—突破"循环，用控制感心流维持追读。
