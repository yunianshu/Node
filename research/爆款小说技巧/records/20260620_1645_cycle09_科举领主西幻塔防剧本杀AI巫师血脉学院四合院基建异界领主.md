## 一、科举文（读书流）

### 题材本质
穿越/重生 + 读书 + 考科举 + 当官 + 朝堂斗争 + 改变时代。男主视角为主，也有女穿男。

### 明清科举四级制（升级主线骨架）
| 级别 | 考试 | 称谓 | 身份意义 |
|------|------|------|----------|
| 一级 | 院试（童试） | 秀才 | 进入士大夫阶层，免丁粮、见知县不跪 |
| 二级 | 乡试（秋闱） | 举人（解元） | 可做官，社会地位质变 |
| 三级 | 会试（春闱） | 贡士（会元） | 取得殿试资格 |
| 四级 | 殿试 | 进士（状元/榜眼/探花） | 皇帝亲定名次 |

### 七大爽点设计
1. **欲扬先抑**：先被轻视再通过考试打脸
2. **慧眼识珠**：伯乐提前识才，"潜龙在渊"期待感
3. **知识碾压**：现代视角引用诗词/算学让古人震惊
4. **放榜时刻**：最高光爽点，浓墨重彩
5. **连中三元**：连续升级爽感
6. **扮猪吃虎/身份反转**：庶子赘婿农家子翻身
7. **朝堂博弈**：考过进入官场，党争/改革/忠奸较量

### 剧情结构
- 前期（寒门读书）20-30% → 中期（科举升级）40-50% → 后期（为官理政）20-30%
- 多线叙事：主线科举仕途 + 副线家族/感情/商战/种田

### 避坑
忌流水账、忌历史硬伤、忌第一人称（网文大忌）、忌跟风无新意。
- 来源：马良 https://maliangwriter.com/blog/chuanyue-lishi-three-way-comparison/

## 二、领主建设 / 领主经营文

### 典型设定
- 主角多穿越/重生为没落贵族、小领主、被分封到荒凉边地的小儿子
- 领主一人说了算，绝对支配权（区别于东方村落种田文）
- 开局荒野/沙漠/破败领地，"从零开始"建设感

### 经营建设写法
- **人口增长**：买奴隶、招流民、迎娶当地居民
- **资源积累**：系统/科技思维/魔法革命发展农业工业军事
- **科技树路线**：用科技思维建设领地
- **"高筑墙、广积粮、缓称王"**三步走

### 三阶段节奏
建设期（慢热积累）→扩张期（实力展示）→争霸期（高潮爽点）。
- 来源：豆瓣 https://m.douban.com/group/topic/161951301/

## 三、西幻（剑与魔法）

### 写作五大维度
| 维度 | 关键建议 |
|------|---------|
| **世界观设定** | 搭建严谨魔法体系，明确种族、社会结构 |
| **文化平衡** | 兼顾西方奇幻厚重感与中国读者可读性 |
| **"剑与魔法"定位** | 聚焦个人冒险叙事，区别于史诗奇幻宏大视角 |
| **主角构思** | 种族身份、社会地位、人物关系、个人理想缺一不可 |
| **文笔要求** | 西幻读者群体要求较高，文笔剧情需精益求精 |

### 难点
奇幻概念过于庞大，不同子类型难点各异，需明确方向。西方文化背景带来**高阅读门槛**。
- 来源：飞书 https://docs.feishu.cn/v/wiki/HvddwL3a5ioBAIkp4gcclLu2nui/a1 ; 知乎 https://www.zhihu.com/question/474750864

## 四、塔防文

### 防御塔四大类（4399体系）
箭塔、兵营、魔塔、炮塔——每类有独有特色，可直接借鉴设计升级树。

### 写作要素
| 要素 | 建议 |
|------|------|
| **世界观** | 以塔防游戏机制为核心，"防御塔=力量体系" |
| **战斗节奏** | 用"波次（Wave）"组织战斗，层层递进Boss收尾 |
| **策略深度** | 资源管理 + 塔位布局 + 克制关系 = 看点 |
| **爽点** | 一塔守关、以少胜多、防御塔暴兵反推 |

### 塔防设计原则（Reddit）
精通与创造力、最大化DPS、路径与迷宫设计、资源经济循环。
- 来源：百度经验 https://jingyan.baidu.com/article/066074d66b965ac3c31cb04d.html

## 五、剧本杀 / 推理本

### 八大推理技巧（林斯谚）
悬念、悬疑、倒叙、误导、线索铺陈、氛围、诡计、意外结局。

### 三大分类
- 注重**逻辑与还原**的推理本
- 注重**情感与演绎**的沉浸本
- 注重**游戏性对抗与阵营**的机制本

### 前期准备
先定**大纲、诡核（核心诡计）、人物**（提前平衡戏份），再填充内容。人物之间产生**参差交互关系**。
- 来源：知乎 https://zhuanlan.zhihu.com/p/376077343 ; 東默農 https://www.domorenovel.com/detective-fiction/

## 六、AI辅助写小说

### ChatGPT核心用法
AI适合担任"辅助角色"——构建大纲、角色设定、世界架构、润色文字、扩展细节，而非完全替代人工。

### 主流工具（2025）
- **马良写作**：AI多智能体协作，7个Agent协同，支持知识图谱/三级大纲/角色管理
- **百度作家平台**：AI续写/润色/扩写/智能连载/一键成文
- **唐库创作网**：一句话灵感自动扩展，最高500万字长篇
- DeepSeek、笔灵AI、豆包、Kimi、文心一言

### 长篇关键挑战
直接让AI无限续写会变成"流水账"，需分章节精细化管理大纲和人设。
- 来源：OpenAI https://openai.com/zh-Hans-CN/chatgpt/use-cases/writing-with-ai/ ; 马良 https://maliangwriter.com/

## 七、巫师流（西幻法师分支）

### 流派核心
- **力量体系**：巫师学徒→正式巫师→高级巫师漫长升级，强调知识积累与资源掠夺
- **世界观**：黑暗、残酷、理性至上的巫师世界
- **与西幻法师区别**：融合科学、芯片、数据分析等"理性"元素

### 金手指类型
- **芯片/智脑流**：《巫界术士》携带AI芯片辅助分析推演
- **系统流**：任务系统获奖励
- **魔药流**：魔药炼制为核心
- **穿越+知识流**：现代科学思维改造巫师体系

### 升级节奏
巫师文是**升级最慢**的奇幻类型之一，几百章甚至上千章才完成大阶段突破。慢节奏需用世界观补完、支线探索、资源获取填充。

## 八、血脉流 / 种族天赋

### 六大技巧
| 维度 | 写法 |
|------|------|
| **血脉觉醒** | 平庸/被封印 → 契机触发觉醒 → 解锁力量 |
| **种族天赋** | 差异化天赋（龙族肉身、精灵魔法），体系化战力层级 |
| **血脉等级** | 凡血→灵血→圣血→神血，明确成长目标 |
| **血脉压制** | 高等血脉压制低等，戏剧冲突和爽感 |
| **血脉溯源** | 探寻源头揭身世之谜，长线悬念 |
| **反差爽点** | "废柴血脉"实则隐藏逆天天赋 |

### 身份设置心法
给主角一个"不能作为"的身份，让读者期待主角有所作为，营造**期待感**。

## 九、魔法学院文

### 魔法系统三大定律（Slima类型写作大师班）
- **第一定律：魔法解决问题的代价**——魔法不能万能，使用必有代价才有张力
- **第二定律：限制创造故事**——越给魔法设边界规则，越催生精彩情节（新手最易忽略）
- **第三定律：深度优于广度**——与其庞大粗浅，不如把细小规则写到极致

### 写作要点
1. **魔法体系**：清晰规则/代价/限制，给读者"规则感"
2. **学院场景**：课程体系、考试竞赛、年级升级制度，"成长路线图"
3. **人物群像**：主角/同学/导师/对手多层次关系
4. **主线+单元剧**：以学期/学年为节奏，每段小高潮
5. **日常与冒险平衡**：上课社团考试 vs 战斗探索穿插
- 来源：Slima https://slima.ai/zh-TW/resources/article/genre-masterclass-01-fantasy

## 十、四合院文（《情满四合院》同人）

### 核心要素
- **角色还原**：何雨柱（外糙内细）、秦淮茹（精于算计善示弱）、许大茂、贾张氏等市井性格
- **时代背景**：20世纪60-80年代北京胡同/四合院，票证制度、大锅饭、工厂文化
- **语言**：融入北京方言、胡同口语

### 常见套路
| 技巧 | 说明 |
|------|------|
| **穿越/重生开局** | 穿越成何雨柱，利用先知优势改变命运 |
| **打脸爽文节奏** | 化解原剧"憋屈"情节，情绪宣泄 |
| **邻里斗智** | "一家有事全院看"的市井氛围 |
| **金手指设定** | 空间/系统/预知剧情，平衡强度与张力 |
| **感情线处理** | 可改CP（如何雨柱不娶秦淮茹），但需合理铺垫 |

### 时代细节
粮票、肉票、自行车、收音机等年代物件增强真实感。

## 十一、基建流 / 攀科技树

### 地图设计（核心）
保持**2+小地图并行**（内部建设地图 + 周边开拓地图），避免单调。

### 攀科技树节奏
设置**外部威胁/deadline**（如金人南下、敌国入侵）驱动科技树推进，制造紧迫感。

### 爽点来源
从无到有的建设感、科技碾压、文明跃迁——"**种的不是田，是文明**"。

### 开局设定
起点要低、配置要差（队友要"猪"），给主角足够成长空间。

## 十二、异界领主 / 召唤文

### 主角塑造心法
"**狡猾≠无赖，没脸没皮≠蠢**"——塑造刘邦式主角时用力过度会失误。角色**初心**要贯穿始终。

### 多线冲突结构
资深玩家/穿越者从边境斥候/小领主起家，一面抵抗外敌，一面应付阴险自私的贵族。

### 数据流爽文写法
- **属性面板清晰**，读者直观看到成长
- **成长路线明确**，节奏明快
- 主打"碾压"与"收割"
- 利用**信息差与天赋优势**制造爽感

### 召唤文开局
穿越→成为领主→召唤玩家/兵种，利用"刁民"属性制造趣味冲突。
- 来源：知乎 https://zhuanlan.zhihu.com/p/510987300 ; 搜狐 https://www.sohu.com/a/314087734_120090965

## 本轮核心结论速记

1. **科举文**：四级考试=升级主线，放榜是最高光爽点，第三人称+多线叙事
2. **领主建设**：绝对支配权，高筑墙广积粮缓称王三步走
3. **西幻**：剑与魔法聚焦个人冒险，平衡西方厚重感与中国可读性
4. **塔防**：箭塔/兵营/魔塔/炮塔四类，波次组织战斗
5. **剧本杀**：先定大纲+诡核+人物，八大推理技巧
6. **AI辅助**：辅助角色定位，主流工具马良/百度/唐库，长篇需分章管理
7. **巫师流**：升级最慢的奇幻类型，芯片/智脑流金手指，黑暗理性风格
8. **血脉流**：觉醒/等级/压制/溯源六技巧，"不能作为"身份造期待
9. **魔法学院**：魔法三定律（代价/限制/深度），主线+单元剧
10. **四合院**：角色还原+时代背景+邻里斗智+打脸爽文
11. **基建流**：2+小地图并行，deadline驱动科技树，"种的是文明"
12. **异界领主**：狡猾≠无赖，多线冲突，属性面板清晰的数据流爽文
