## 一、书名取名技巧

### 5个爆款公式 + 3类雷区（网文666）
八大平台（番茄/起点/晋江/飞卢/七猫/纵横/QQ阅读/书旗）书名风格全部对照。

| 技巧要点 | 说明 |
|---------|------|
| **一看就懂类型** | 书名让读者一眼识别题材（《江山为聘：帝后无双》一看就是古言） |
| **突出核心看点** | 嵌入最大卖点（身份反转/金手指/世界观） |
| **爆款句式** | "我在XX做XX"、"XX之XX"、"重生XX" |
| **避开俗套雷区** | 太长/太文艺/太抽象/与类型不匹配 |

### 独特性原则
避免俗套常见书名，独特才能脱颖而出（如《我在精神病院学斩神》）。

## 二、简介文案写法

### 核心定位
简介是对**书名的补充**、**正文的概括**，决定读者是否点开第一章。

### 关键技巧
1. **主线方向要具体**：不用"波诡云谲""残酷世界"等空泛词堆砌
2. **内容与书名呼应**：否则给读者"挂羊头卖狗肉"的感觉
3. **突出亮点**：把故事最精彩部分简单概括
4. **产生共鸣**：用具体细节描述与读者相关场景
5. **别故作高深**

### 5个简介雷区（网文666）
- 文不对题（题材标签错配）
- 字数过多拖沓
- 剧透太多
- 缺乏钩子（悬念）
- 没有核心卖点

### AIDA理论应用
**注意→兴趣→渴望→行动**，设计简介节奏。
- 来源：知乎 https://zhuanlan.zhihu.com/p/90425667 ; 网文666 https://wangwen666.com/post/210.html

## 三、章节结构设计 / 章尾钩子

### "章尾钩子13式"精简版
- **悬念式**（抛新谜题）
- **转折式**（剧情反转）
- **危机式**（主角陷入险境）
- **信息差式**（读者知道而角色不知道）
- **抉择式**（主角面对关键选择）

### 章节节奏分布模板（麟狐AI）
| 阶段 | 章节 | 目标 |
|------|------|------|
| **开篇章** | 前3章 | 快速建立人设+抛第一个钩子；1章内出现"打脸/身份反差/冲突爆发" |
| **上升期** | 每3-5章一次小高潮 | 每10章一次大转折 |
| **中盘** | —— | 提升爽点密度，维持情绪曲线 |

### 重要提醒（知乎）
不提倡**每章都埋钩子**，要兼顾故事流畅度，更应关注**两章之间的衔接关系**。

### 《救猫咪》理论
三幕结构 + 十五个故事节奏点 + 四十个场景：开场→催化事件→冲突升级→高潮→结局。
- 来源：马良 https://maliangwriter.com/blog/novel-pacing-hook-design-guide/ ; 知乎 https://www.zhihu.com/question/1983629597837899405

## 五、网文IP影视化改编

### "三强"原则（欧阳友权）
✅ **强故事性**——有波澜、有起伏、有冲突
✅ **强人物塑造**——人物立体鲜明
✅ **强镜头感**——具备视觉化呈现潜力

### 核心理念：先有人再立文
适合影视改编的小说一定要有**成功人物形象 + 主角光环**。

### 数据选IP（4100万条评论分析）
IP在**"个体激励""人物""情节"**三指标获更高认同 → 改编成功率更高。

### 叙事重构（何亮·北电）
网文向影视改编需对**故事结构重塑**，从长篇连载转化为有**视觉冲击力**的剧集。

## 六、平台运营与数据指标

### 起点 vs 番茄对比
| 维度 | 起点中文网 | 番茄小说 |
|------|-----------|---------|
| 商业模式 | 付费阅读（VIP订阅） | 免费阅读+广告变现 |
| 核心指标 | 订阅量、月票、推荐票 | 有效阅读量、广告CPM、CTR、完读率 |
| 推荐机制 | 编辑推荐+数据综合 | 纯算法，数据决定流量，无人工干预 |
| 月活 | ~1830万 | ~1.75亿 |
| 作者收入 | 订阅分成+打赏 | 阅读时长+广告分成 |

### 番茄商业模式本质
**买量吸引用户 → 广告将阅读时长变现**，纯互联网流量产品。

### "有效阅读量"定义
用户阅读某章节时长超过一定阈值才算有效。

## 七、短篇小说（知乎盐选）

### 核心要素
**第一人称 + 炸裂开头 + 精准卡点 + 快节奏 + 强烈冲突 + 脑洞设定**

### 爆款底层逻辑
**爆款 = 强情绪共鸣 + 明确爽点/痛点 + 易传播**
背后是"结构 + 情绪 + 价值 + 巧劲"的综合体。

### 关键参数
- 字数：1万~1.5万字即可
- 视角：第一人称代入感最强
- 转化率导向：有多少读者被吸引开通盐选会员

### 方法论
拆解爆款 → 模仿 → 形成自己的模板。关注构思方式：起因→发展→高潮→结尾，尤其注意**转折点设在哪里**。

## 八、神豪流

### 核心要素
| 要素 | 说明 |
|------|------|
| **金手指设定** | 系统流/重生流/意外获得财富来源 |
| **消费剧情节奏** | "先取后予、先抑后扬"，花销有爽感和层次感 |
| **开篇黄金三章** | 快速切入，简洁交代故事核心 |
| **避免套路化** | 单纯"炫富"已不吸引人，需创新角度和情感冲突 |
| **情绪调动** | 本质是情绪消费，精准打击读者"爽点" |

### 读者反馈关键点（NGA）
**神豪文不是看创业发家，也不是看傻子花钱**——过于套路化、不动脑的情节读者已不买账。

## 九、种田/经营流

### 核心本质：壮大自身势力
不依赖个体实力，而是从更高一层角逐去击败竞争者。

### 三大乐趣来源
1. **怎么种**（经营建设过程）
2. **种完后的成果**（收获反馈）
3. **竞争者的反馈**（对抗与博弈）

### 核心驱动力：正向反馈循环
种→收获→升级→更大的种。

### 关键提醒
- 种田与经营**只是方法，不能单独作为核心卖点**
- 纯种田会平淡，需融入竞争、对抗、危机等戏剧元素
- 纯家长里短几十万字很难吸引读者，必要宅斗/对抗提升戏剧性
- 来源：作家助手·二目 https://m.write.qq.com/portal/article/detail?CAID=23342368201079601 ; 知乎 https://zhuanlan.zhihu.com/p/342985359

## 十、御兽流

### 核心定位：真正的主角是宠兽
需像刻画人物一样塑造宠兽的性格与经历。

### 受众心理（源于现实养宠）
- 陪伴感、养成感、共同成长的爽感

### 契约形式创新
不限于传统妖兽——可拓展至**龙族、植物、机械、死灵、精灵**等，发挥想象力。

### 设定创新点
- 进化体系
- 心结解锁（宠物进阶需解开"心结"）
- 契约种类多样化

## 十一、悬疑推理·诡计设计

### 诡计四大分类
- **密室/空间诡计**
- **叙述性诡计**（利用文章结构/文字技巧"玩文字游戏"误导读者）
- **逻辑流诡计**
- **障眼法**

### 设计框架
**Who（谁）/ How（怎样）/ Why（为什么）** 三要素 + **室内/室外/边界**空间模型。

### 实操流程
线索铺陈 → 误导 → 反转 → 揭露真相，层层递进。

### 林斯谚八技巧
悬念、悬疑、倒叙、误导、线索铺陈、氛围、诡计、意外结局。

## 十二、历史权谋/宫斗宅斗

### 宫斗核心公式
**某人基于某个动机，用某物害了某人** —— 兼具推理小说的悬念感。

### 宫斗 vs 宅斗 vs 权谋
- **宅斗**：侧重家族内部
- **宫斗**：侧重后宫朝堂，格局递进
- **权谋**（男性视角）：更显深沉、大气、开阔，或在庙堂、或在江湖、或为家国、或为忠义

### 权谋写法
需构建多层次**阳谋/阴谋体系**（B站"198种阳谋阴谋"素材库）。

### 事业线弥补感情线
权谋宫斗文因强大的事业线，可掩盖作者薄弱的感情线——是言情苦手作者的好选择。
- 来源：豆瓣 https://m.douban.com/note/686283102/ ; 飞书 https://docs.feishu.cn/v/wiki/EpVJwNJAZiNtiQkcNdTcNVA2nNc/aa

## 本轮核心结论速记

1. **书名**：一看懂类型 + 爆款句式 + 避俗套
2. **简介**：AIDA节奏 + 5雷区（文不对题/字数多/剧透/缺钩子/无卖点）
3. **章尾钩子13式**，但不必每章都埋，重两章衔接
4. **爆款数据**：起点165天10万均订；番茄近十亿扶持短剧IP
5. **影视化"三强"**：强故事+强人物+强镜头感，"先有人再立文"
6. **平台**：起点付费(订阅/月票) vs 番茄免费(阅读时长/广告CPM)
7. **短篇**：爆款=强情绪共鸣+明确爽点+易传播
8. **题材各有道**：神豪(情绪消费)/种田(正向反馈循环)/御兽(宠兽为主角)/悬疑(Who-How-Why)/宫斗(动机+手段+受害者)
