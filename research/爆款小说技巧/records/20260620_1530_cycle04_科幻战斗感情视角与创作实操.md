## 一、科幻小说（硬科幻/软科幻）

### 经典比例（雨果·根斯巴克）
好的科幻应是 **75%幻想 + 25%科学**。

### 硬科幻 vs 软科幻
| 维度 | 硬科幻 | 软科幻 |
|------|--------|--------|
| 科学设定 | 严谨准确，接近真实科学 | 不必严谨，可适当虚构 |
| 技术细节 | 丰富详细，有理论支撑 | 作为故事道具，点到即止 |
| 叙事重心 | 科技发展和逻辑推演 | 人物塑造与情感表达 |
| 知识储备 | 需深入了解相关科学领域 | 更关注社会科学和人文 |

### 四大写作建议
1. **科幻概念贯穿始终**：至少一个科幻概念作为核心
2. **设定要自洽**：软科幻内部也需逻辑一致
3. **量力而行**：科学知识有限选软科幻，避免硬科幻"翻车"
4. **幻想与科学平衡**
- 来源：中国作家网 http://www.chinawriter.com.cn/n1/2019/1216/c404080-31508413.html

## 二、战斗/打斗场面描写

### 五觉法（核心）
视觉、听觉、嗅觉、味觉、触觉——多感官描写增强画面感。

### 战斗核心卖点是"逆转"
除一刀秒杀外，大段落战斗**最核心卖点在于"逆转"**。

### 八大技巧
| 技巧 | 要点 |
|------|------|
| **五觉法** | 多感官描写 |
| **短句快节奏** | 用短句加快节奏，营造紧张感 |
| **避免上帝视角** | 以角色视角代入，忌流水账 |
| **设计"逆转"** | 核心卖点 |
| **动作优先** | 侧重人物动作，而非详细描写武器 |
| **正面+侧面结合** | 直接描写+旁观者反应烘托 |
| **动词力量** | 精准有力动词（斩、劈、贯穿） |
| **三段式** | 原因→准备/铺垫→过程与结果 |

## 三、感情线 / CP设计

### 两种基本模式
- **感情流**：以感情线为主线，剧情服务感情（通篇谈恋爱）
- **剧情流**：事业冒险为主线，爱情为副线

### 经典发展模板
**初识 → 感情萌芽 → （情敌）→ 互表心意 → （情敌）→ 甜蜜 → 经历风浪 → 圆满**

### 节奏要诀
**前快后慢**：快速出场认识熟悉 → 漫长磨合相处。

### 心理描写要克制
大部分作者写到**第二层**（逻辑闭合）即可，心理描写过多拖慢节奏。

## 四、视角选择

### 第一人称 vs 第三人称
| 维度 | 第一人称（"我"） | 第三人称（"他/她"） |
|------|------------------|---------------------|
| 代入感 | 强，易共鸣 | 较弱，心理距离远 |
| 视野 | 受限，只能写"我"所见 | 广阔，可多角色切换 |
| 悬念 | 天然（叙述者不知道读者也不知道） | 需刻意设计 |
| 适用 | YA、悬疑、个人成长 | 史诗、群像、宏大叙事 |
| 难点 | 维持角色"声音"一致，难掌控全局 | 容易"视角混乱" |

> 第三人称细分为：**全知（上帝视角）**和**有限（锁定某角色）**。
- 来源：知乎 https://zhuanlan.zhihu.com/p/517587633

## 五、开新书立项选题步骤

### 七步法
1. **明确创作目的**：作品 vs 商品
2. **市场调研与选题**：了解热门题材、读者口味、平台调性
3. **确定核心立意**：有辨识度的核心卖点/创意点
4. **选择投稿平台**：题材匹配平台读者群
5. **大纲与世界观搭建**
6. **撰写开篇与试写**：打磨前三章/前一万字
7. **评估更新能力**：确认能否稳定日更/周更

### 中国作协选题申报
- 字数20万字以上原创作品
- 鼓励创新，严禁抄袭

## 六、更新频率 / 日更字数

### 主流日更字数
| 字数 | 反馈 |
|------|------|
| 日更3000 | 读者有兴趣订阅、追更 |
| 日更4000 | 男频"隐形门槛" |
| 日更6000 | 读者基本满意 |
| 日更8000 | 大神级目标 |
| 日更10000 | 高产作者水准 |

### 章节设置
- 每天3~4章为宜
- 每章2000~4000字（番茄建议2050-2300字/章，利于有声+冲奖励）
- 更新时间**固定有规律**

### 日万技巧（存稿打法）
每天码4000-8000字，正常发布2000-6000字，余下存稿，积攒3个月存稿较合理。月初/月底开文利于冲全勤。

## 七、毒点雷区（读者弃书）

### 五大雷区
| 类别 | 典型毒点 |
|------|----------|
| **人设类** | 圣母白莲花、无底线原谅敌人、性格前后矛盾 |
| **情节类** | 强行虐主、逻辑崩坏、节奏拖沓 |
| **角色安排** | 女主处理不当、配角喧宾夺主 |
| **价值观类** | 与目标读者群体价值观冲突 |
| **文案欺诈** | 文案与正文严重不符 |

### 关键认知
读者（尤其新媒体读者）**喜恶分明**，一旦涉及毒点，损失**不可逆**。"甲之蜜糖，乙之砒霜"——不同读者群体接受度差异巨大。

## 八、配角"工具人"问题及解决

### 工具人定义
角色形象单薄，**仅为衬托主角/推动剧情/满足爽感而存在**，缺乏独立人格与动机。

### 四大解决方案
1. **给配角"独特记忆点"**——具体能画面化的小细节，而非性格标签
2. **戏份要适度**——不能抢主角戏份，避免连续十几章无主角的"配角专场"
3. **赋予独立动机**——让配角有自己想要的东西，拥有人物弧光
4. **避免模板化**——拒绝惰性思维，拒绝套路挪用

### 戏份原则
配角戏份要根据故事需要来定，**戏份多是故事需求，不是错漏**，关键在主配角平衡。

## 十、环境/场景描写

### 氛围营造核心公式
> **氛围 = 感官细节（视/听/嗅/触/味）+ 光影色彩 + 动静对比 + 情感投射 + 精炼取舍**

### 关键原则
想营造什么氛围就往什么方向写，**不面面俱到，避免流水账**。

### 用光线传达氛围（雷恩·霍尔）
"要传达一个地方的氛围，就写一句**光线从何处来、是什么颜色和质感**的描写。"可营造诡异、粗粝、浪漫、乐观、压抑、凌厉……

### 环境描写五大作用
1. 交代背景 2. 烘托氛围 3. 暗示心理 4. 推动情节 5. 深化主题

## 十二、同人小说

### 核心要点
| 关键点 | 说明 |
|--------|------|
| **熟悉原作** | 深入理解角色性格/经历/说话方式，避免OOC（角色崩坏） |
| **大量阅读** | 写前至少看100篇同类型CP文，了解套路与读者偏好 |
| **先列大纲** | 先搭骨架再填细节 |
| **培养文风** | 持续写作形成个人风格 |
| **注意视角** | 避免频繁切换视角 |
| **善用"梗"** | 同人圈梗与读者期待 |

### OOC（Out of Character）
角色偏离原作人设——同人创作最大忌讳，需深入理解原作。

## 本轮核心结论速记

1. **科幻**：75%幻想+25%科学，硬科幻严谨/软科幻重人文，设定必自洽
2. **战斗**：五觉法+短句+逆转，核心卖点是"逆转"非对砍
3. **感情线**：前快后慢，心理描写写到第二层即可
4. **视角**：第一人称代入强/受限，第三人称灵活/易乱
5. **日更**：4000-6000起步，8000-10000冲全勤，存稿打法3个月缓冲
6. **毒点不可逆**：圣母白莲花是头号弃书原因
7. **配角**：给独特记忆点+独立动机，拒绝模板化
8. **氛围=五感+光影+动静+情感+取舍**
