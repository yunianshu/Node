# 古龙风格小说生成工作流 v2

> 基于《古龙写作特点深度分析》的12维度解构，构建一套**风格内生型**工作流。
> 目标：不仅不走偏，更让AI内化"古龙会怎么做"，生成有灵魂而非仅合规的文字。
> v2 新增：L0风格示范库、正面特征密度、读者情感验证、主题锚定回传、跨章记忆矩阵、场景预演、动态风格密度、风格疲劳度、修正成本评估、角色面具切换。

---

## 一、风格锚点系统（Style Anchor System）

### 1.1 核心锚点（Core Anchors）—— 绝对不可偏离

| 锚点ID | 锚点名称 | 具体定义 | 偏离检测关键词 |
|---|---|---|---|
| CA-01 | 去历史化 | 不设定具体朝代，不涉民族国家大义，江湖是抽象存在主义场域 | "宋朝"、"元朝"、"国家"、"民族"、"朝廷" |
| CA-02 | 极简诗化散文体 | 行文极简、极短、极留白；诗化意象叠加；电影蒙太奇式场景切换 | 长段落铺陈、工笔白描、详尽场景描写 |
| CA-03 | 不写招式写意境 | 武功对决绝不描写招式名称/动作分解，只写速度、意境、结果 | "招式"、"剑法第X式"、"运起内力"、"一招XX" |
| CA-04 | 存在主义内核 | 核心冲突是人与命运/自我的对抗，非正邪对立；结局开放悲怆 | 大团圆、正义必胜、反派彻底覆灭 |
| CA-05 | 对话三极 | 对话极短（≤10字占28%）、极简、极深；大量潜台词 | 长篇对话、解释性对话、直白说教 |

### 1.2 次级锚点（Secondary Anchors）—— 优先遵守

| 锚点ID | 锚点名称 | 具体定义 | 偏离检测 |
|---|---|---|---|
| SA-01 | 道家哲学底色 | 大道至简、无为、反者道之动；"寂寞"为核心情感基调 | 儒家说教、佛家因果轮回详述 |
| SA-02 | 人物命名意象化 | 名字=意象=性格；可用反讽/哲学隐喻/极简型 | 普通姓氏+普通名字的随机组合 |
| SA-03 | 环境氛围优先 | 不写环境写氛围；以气象写心境、以声音写寂静、以细节写全貌 | 全景式地理描写、建筑陈设详述 |
| SA-04 | 悬念驱动叙事 | 谜团先行→人物后至；非线性情感线；信息渐进重配 | 线性因果叙事、平铺直叙 |
| SA-05 | 反成长弧光 | 人物从伪装走向真实，非从幼稚走向成熟 | 传统成长励志、能力逐级提升 |

### 1.3 锚点记忆卡（Prompt 注入格式）

```
【古龙风格宪法】
1. 去历史化：无朝代，无国家，无民族。江湖是抽象场域。
2. 极简诗化：短句独立成段，意象叠加，留白，不言尽。
3. 不写招式：武功只写速度/意境/结果，零招式名称。
4. 存在主义：核心冲突是人vs命运/自我，结局开放悲怆。
5. 对话三极：极短、极简、极深。潜台词 > 字面意思。
6. 道家底色：大道至简，无为，反者道之动，寂寞为基调。
7. 氛围优先：以气象写心境，以声音写寂静，以细节写全貌。
8. 悬念驱动：谜团先行，信息渐进重配，非线性叙事。
9. 反成长：人物从伪装剥落到真实，非从弱到强。
```

## 二、L0 层：风格示范库（Style Demonstration Library）

> v2 新增。在正式生成前，让AI通过"正面对照模板"内化古龙风格，而非仅记住抽象规则。

### 2.1 目的

抽象规则容易变成"正确的废话"。AI知道要"极简"但写不出来，因为缺少"普通→古龙"的转换肌肉记忆。

L0 提供一组**正面对照模板**：同一意思的普通写法 vs 古龙式写法。生成前让AI阅读并内化这些转换模式。

### 2.2 行文转换模板

| 维度 | 普通写法（偏离） | 古龙式转换（符合） | 转换原理 |
|---|---|---|---|
| 年龄描写 | 他今年三十五岁，身穿青衫，腰悬长剑，相貌英俊，眉宇间有一股傲气。 | 他已不再年轻。青衫如洗，长剑如冰。 | 删除一切解释性信息，只留意象并置 |
| 环境描写 | 桃花岛上有一片桃林，桃花盛开，花瓣粉红，香气扑鼻，美不胜收。 | 桃花如血。落了一地。 | 四要素（色彩+动作+结果+情绪）压缩为两句 |
| 时间描写 | 那是一个深秋的夜晚，月色昏暗，北风呼啸，让人感到格外凄凉。 | 月如残刀。风如泣。 | 删除主观感受词（"让人感到"），让意象自身说话 |
| 心理描写 | 他心中充满了悲伤和愤怒，觉得自己被全世界背叛了。 | 他的刀在鞘中。他的手在刀上。 | 心理不直接说，用动作物化 |
| 身份交代 | 他是江南第一剑客，师承名门，武功高强，江湖上无人不知。 | 他的名字，本身就是一种恐惧。 | 不铺陈履历，只写效果/他人反应 |

### 2.3 对话转换模板

| 普通写法（偏离） | 古龙式转换（符合） | 转换原理 |
|---|---|---|
| "我觉得你说得不对，因为江湖上的规矩不是这样的，我们应该按照约定行事。" | "你错了。" | 三句话→三个字，删除一切论证和解释 |
| "你为什么不肯告诉我真相？难道我们之间连这点信任都没有吗？" | "你不说？" "不说。" | 质问→追问→沉默，情感在间隙中 |
| "我很感激你救了我，以后我一定会报答你的恩情。" | 他看着这个人，看了很久。 "我欠你一条命。" | 删除情感标签（"感激"），用行动和极简承诺替代 |
| "我不管你怎么想，反正这件事我是绝对不会放弃的，哪怕死也要做到。" | "没有人能阻止我。" 他一字字道。 | 删除修饰语和条件句，只剩决心 |

### 2.4 武打场景转换模板

| 普通写法（偏离） | 古龙式转换（符合） | 转换原理 |
|---|---|---|
| 张三拔出剑，使出一招"长虹贯日"，剑气如虹，向对方刺去。对方连忙格挡，但张三变招更快，剑锋一转，直取咽喉。 | 剑已出鞘。没有人看清这一剑。 | 删除招式名、动作分解、攻防回合，只写速度 |
| 两人交手数十招，各自运起毕生功力，掌风呼啸，内力激荡，周围的桌椅纷纷碎裂。 | 然后就有了风。不是掌风。是死亡的风。 | 不写招式过程，写氛围质变 |
| 他的内力深厚，已经将真气运行于丹田，再沿任督二脉流转，凝聚于掌心，准备发出致命一击。 | 他的手掌很白。白得像雪。也像死亡。 | 删除内功运行描写（古龙从不写），用意象暗示危险 |

### 2.5 命名转换模板

| 普通写法（偏离） | 古龙式转换（符合） | 命名原理 |
|---|---|---|
| 李强 | 李无迹 | 无迹=漂泊=无根，暗示人物身世 |
| 张美丽 | 张残月 | 残月=不完整=遗憾，暗示命运 |
| 王大力 | 王断山 | 断山=决绝=不可逾越，暗示性格 |
| 赵小宝 | 赵无名 | 无名=拒绝命名=存在主义，暗示身份 |

### 2.6 L0 注入指令

在每次进入 L1 之前，执行：

```
【风格示范库注入】
请仔细阅读以下"普通写法→古龙式转换"的正面对照模板。
你的任务不是背诵规则，而是理解**转换原理**——古龙为什么这样写？
核心原理：删除解释，保留意象；删除感受词，让意象自身说话；删除过程，只写结果和速度。

阅读完毕后，请用一句话总结：古龙式写作的本质是______。
（期望答案方向："用最少的信息触发最多的想象"或"意象并置替代因果叙述"）
```

## 三、分层生成架构（Layered Generation Architecture）

```
L0: 风格示范库注入（前置校准）
    ↓
Layer 1: 世界观与基调设计（World & Tone）
    ↓ [通过L1约束检查]
Layer 2: 故事大纲与人物谱系（Outline & Characters）
    ↓ [通过L2约束检查]
Layer 3: 章纲与场景序列（Chapter Blueprint & Scenes）
    ↓ [通过L3约束检查]
Layer 3.5: 场景预演（Scene Rehearsal）← v2 新增
    ↓ [通过L3.5约束检查]
Layer 4: 段落与对话生成（Paragraph & Dialogue）
    ↓ [通过L4约束检查]
成品输出
```

## 四、L1 层：世界观与基调设计

### 4.1 输入
- L0 通过的风格示范库内化确认
- 用户提供的核心创意（一句话概念）
- 可选：主角名字意象、关键道具、核心情感基调

### 4.2 生成任务
生成以下内容：
1. **世界观三层结构**（必须包含）：
   - 表层：金钱与权力的丛林逻辑
   - 中层：友情的乌托邦（核心关系）
   - 深层：存在主义荒原（终极图景）
2. **基调关键词**（3-5个）：从"寂寞、孤独、命运、生死、虚空"中选取或衍生
3. **江湖规则**（3条）：定义这个江湖的独特运转法则（不写门派体系，不写武功层级）
4. **主题宣言**（v2 新增，1句话）：本书的哲学内核。例："人在行走中寻找意义，而意义就在行走本身。"

### 4.3 L1 约束检查清单

```
□ CA-01 检查：无具体朝代、无国家概念、无民族叙事？
□ CA-04 检查：核心冲突是否指向人与命运/自我，而非正邪对立？
□ SA-01 检查：是否有道家哲学底色痕迹？基调是否偏向"寂寞"？
□ SA-03 检查：环境描写是否定位于"氛围"而非"景观"？
□ 主题检查（v2 新增）：主题宣言是否存在主义层面？是否可指导后续所有场景设计？
□ 整体检查：世界观是否足够抽象/存在主义，而非社会写实？
```

### 4.4 L1 纠偏规则
- **若检测到朝代/国家/民族**：立即删除，替换为抽象时空描述。如"大宋年间"→"很多年以前"。
- **若核心冲突变为正邪对立**：重新定义冲突为"主角与自身某一面/与宿命规则的对抗"。
- **若基调偏暖/励志**：加入"寂寞""孤独""虚无"等关键词，并说明这种孤独如何渗透世界观。
- **若主题宣言缺失或平庸**（v2 新增）：要求重写。主题宣言必须是"一句话哲学"，不是情节摘要。

## 五、L2 层：故事大纲与人物谱系

### 5.1 输入
- L1 通过检查的世界观、基调与**主题宣言**

### 5.2 生成任务
生成以下内容：
1. **人物谱系**（每个角色包含）：
   - 名字（必须说明意象来源和性格暗示）
   - 表面身份 vs 真实内核
   - 核心欲望（存在主义层面，非功利层面）
   - 与他人关系（核心关系应为男性友情）
2. **故事骨架**（非线性结构）：
   - 开篇谜团（不先交代人物，先抛事件）
   - 主要悬念链（3-5个递进谜团）
   - 情感线（非线性：固化/遗憾/不可重来）
   - 结局类型（从"孤独行走/真相未明/反讽和解/宿命轮回/意犹未尽"中选择）
3. **核心道具伏笔**（1-2个）：以物象承载命运
4. **主题锚定图**（v2 新增）：
   - 列出5-8个关键场景/情节
   - 每个标注：是"走向"主题还是"背离"主题
   - "背离"项必须说明如何制造张力并最终回归主题（反者道之动）

### 5.3 L2 约束检查清单

```
□ CA-05 检查：人物对话设计是否预留了潜台词空间？
□ SA-02 检查：每个人物名字是否都有意象解释？是否避免普通命名？
□ SA-04 检查：叙事结构是否谜团先行？情感线是否非线性？
□ SA-05 检查：人物弧光是否"反成长"（从伪装到真实）？
□ 人物检查：核心关系是否为男性友情？是否避免传统爱情线主导？
□ 冲突检查：三层冲突结构是否清晰（人→人 / 人→命运 / 人→自我）？
□ 主题检查（v2 新增）：主题锚定图中是否有"背离→回归"的辩证设计？
```

### 5.4 L2 纠偏规则
- **若人物名字无意象**：强制改名。例："张三"→"张无迹"（无迹=漂泊=无根）。
- **若情感线为线性爱情**：改为"已有遗憾/无法重来"的固化模式，或让友情占主导。
- **若人物弧光为成长励志**：改为"剥落"模式——剥去伪装，露出更脆弱但更真实的内核。
- **若悬念链线性因果**：插入"信息渐进重配"节点——每个新信息都改变此前信息的解读。
- **若主题锚定图中无"背离"项**（v2 新增）：要求增加至少2个"背离"项。古龙的主题从不是直线推进，而是"反者道之动"。

## 六、L3 层：章纲与场景序列

### 6.1 输入
- L2 通过检查的大纲、人物谱系与**主题锚定图**
- **主题宣言**（贯穿所有层级的引力源）

### 6.2 生成任务
逐章生成以下内容：
1. **每章场景列表**（每章3-7个场景）：
   - 场景类型：对话场景 / 对决场景 / 独白场景 / 氛围场景
   - 场景功能：推进谜团 / 揭示人物 / 埋设伏笔 / 氛围渲染
2. **场景氛围标注**：
   - 每个场景标注核心氛围词（如"荒寒""死寂""压抑""诡谲"）
   - 标注环境描写策略（气象写心境 / 声音写寂静 / 细节写全貌）
3. **对话密度标注**：
   - 标注哪些场景以对话驱动（古龙叙事中对话占比极高）
   - 标注关键对话的潜台词层次
4. **伏笔分布图**：
   - 明确每章埋设/呼应的伏笔（行为模式/身份/道具）
5. **主题回传标注**（v2 新增）：
   - 每个场景标注与"主题宣言"的关系：支撑/背离/辩证
   - 若标注为"背离"，必须同时标注预期在哪一章回归

### 6.3 动态风格密度配置（v2 新增）

不同场景类型应有不同的风格密度，避免每章均匀乏味。

| 场景类型 | 短句密度 | 意象叠加密度 | 留白比例 | 对话密度 | 环境策略 |
|---|---|---|---|---|---|
| 对决场景 | 极高（80%+） | 低 | 极高 | 极低（≤10%） | 不写环境，只写速度 |
| 对话场景 | 高（50%） | 中 | 高 | 极高（80%+） | 声音写寂静 |
| 氛围场景 | 低（20%） | 极高（每100字1处） | 极高 | 低 | 气象写心境 |
| 过渡场景 | 中（40%） | 中 | 中 | 中 | 细节写全貌 |
| 结局场景 | 极高（70%） | 高 | 极高 | 中 | 意象收束 |

### 6.4 L3 约束检查清单

```
□ CA-02 检查：场景切换是否可用蒙太奇式跳跃？是否有留白设计？
□ CA-03 检查：对决场景是否只写意境/速度/结果，零招式？
□ SA-03 检查：每个场景的环境描写是否服务于心境/氛围？
□ SA-04 检查：每章结尾是否留有悬念或新谜团？
□ 节奏检查：场景节奏是否长短交错（短→长→短）？
□ 对话检查：对话场景占比是否足够高？关键对话是否有潜台词设计？
□ 密度检查（v2 新增）：各场景的风格密度是否符合"动态风格密度配置"？
□ 主题检查（v2 新增）：每个场景是否标注了与主题宣言的关系？
```

### 6.5 L3 纠偏规则
- **若场景描写过于详尽**：删除景观描写，保留氛围暗示。例："桃花岛上有一片桃林，桃花盛开，花瓣粉红"→"桃花如血，落了一地。"
- **若对决场景出现招式**：删除招式名称，替换为速度/意境描写。例："他使出一招'长虹贯日'"→"他的剑已刺出。没有人看清这一剑。"
- **若场景节奏平铺直叙**：调整场景顺序，加入独立短句场景。例：在长篇对话后插入一句独立成段的叙述。
- **若悬念感不足**：每章结尾强制加入一个未解问题或意外信息。
- **若某章全部场景都是"支撑"主题**（v2 新增）：强制插入至少1个"背离"场景。古龙的主题表达从不直白。

## 七、L3.5 层：场景预演（Scene Rehearsal）—— v2 新增

> 介于章纲和正文之间的关键层。正式写段落前，先用极简语言预演该场景的古龙风格处理，确认方向正确后再展开。

### 7.1 目的

L3到L4跨度太大：章纲通过了，但展开成段落时风格执行容易走形。场景预演用3-5句"压缩版"验证风格方向，低成本纠错。

### 7.2 输入
- L3 通过检查的章纲与场景序列
- 当前需要预演的具体场景

### 7.3 生成任务
为每个场景生成**预演脚本**（3-8句）：

```
场景预演格式：
1. 开篇句（1句）：以独立短句或意象叠加建立场景基调
2. 人物入场（1-2句）：不写外貌，只写动作/姿态/道具
3. 核心张力（1-2句）：对话或氛围，展示本场景的关键冲突/信息
4. 收束句（1句）：留白、悬念或意象定格
```

预演脚本不追求完整，只追求**风格正确**。

### 7.4 预演示例

场景：主角在雪夜酒馆遇到神秘刀客

预演脚本：
```
雪落无声。
酒已温了三次。他没有喝。
门口的风铃响了。进来的人没有拍去肩上的雪。
"你在等人？" "我在等刀。"
雪落满了他的刀鞘。
```

预演检查通过 → 展开为完整场景
预演检查不通过 → 重写预演，而非重写完整场景（低成本纠错）

### 7.5 L3.5 约束检查清单

```
□ 开篇检查：是否以极简短句或强意象开场？
□ 人物检查：是否零外貌描写？是否以动作/道具暗示人物？
□ 张力检查：核心冲突/信息是否在3句话内建立？
□ 收束检查：是否以留白/悬念/意象收束？
□ 风格检查：是否符合L2定义的"主题宣言"方向？
□ 正面特征检查（v2 新增）：预演脚本是否包含至少1个古龙标志性技法？
  （独立短句 / 意象叠加 / 留白 / 潜台词 / 以X写Y）
```

### 7.6 L3.5 纠偏规则
- **若预演超过8句**：压缩。预演的目的是验证方向，不是写小段落。
- **若预演中出现招式/外貌描写**：立即重写，参考L0转换模板。
- **若预演读完没有"寂寞""孤独""命运"感**：增加道家氛围词或意象暗示。
- **若预演与主题宣言方向不一致**：调整收束句的方向，确保张力走向正确。

## 八、L4 层：段落与对话生成

### 8.1 输入
- L3 通过检查的章纲与场景序列
- L3.5 通过检查的**场景预演脚本**
- 当前需要生成的具体场景

### 8.2 角色面具切换（v2 新增）

单AI完成创作+审查会认知疲劳。L4引入**角色面具切换**：

```
生成阶段 → 佩戴"古龙"面具
   "你现在是古龙。你在写一个场景。不要解释，只写意象。"

检查阶段 → 佩戴"审查官"面具
   "你现在是风格审查官。冷峻、苛刻、不讲情面。逐条检查刚才的段落。"
```

切换指令：
```
【面具切换】
现在请摘下"作家"面具，戴上"审查官"面具。
你的唯一任务是找出这段文字中所有不符合古龙风格的地方。
不要留情。不要因为是自己写的就放过。
```

### 8.3 生成任务

基于场景预演脚本展开为完整段落。遵循以下技术规范：

#### 8.3.1 行文技术规范

| 技术项 | 规范 | 示例 |
|---|---|---|
| 短句比例 | 独立短句（≤5字）占2-3%；每章至少5处独立成段的短句 | "他已不再年轻。" |
| 长短节奏 | 段落长度交替：短→中→长→短，如波浪 | 见02-长短句与道家思想.md |
| 意象叠加 | 每300字至少1处多意象叠加 | "冷风如刀，以大地为砧板，视众生为鱼肉。" |
| 留白密度 | 关键信息不直接说出，暗示/悬置 | 不说"她是谁"，只说"他所雕刻的永远是同一个人" |
| 比喻密度 | 每150-200字出现一次比喻 | "他的刀如天涯般辽阔寂寞" |

#### 8.3.2 对话技术规范

| 技术项 | 规范 | 示例 |
|---|---|---|
| 极短对话 | 对话中≤10字的短句占25-30% | "我喝不起。" "好，你走吧。" |
| 标记词 | 适当使用"冷冷道/柔声道/喃喃道/一字字道/缓缓道" | "他一字字道：'没有人能阻止我。'" |
| 潜台词 | 每段重要对话必须有至少一层潜台词 | "只因你是我朋友中，看到我咳嗽，却没有劝我戒酒的第一个人。" |
| 哲学追问 | 每2-3章至少一段对话突然转向存在主义追问 | "其实虎狼只为了生存才杀人，人却可以不为什么就杀人。" |

#### 8.3.3 武打场景技术规范

| 技术项 | 规范 | 示例 |
|---|---|---|
| 速度不可见 | 强调"没有人看清" | "但却没有一个人看清他这柄剑是如何刺入白蛇咽喉的！" |
| 时间冻结 | 用血未流下等细节冻结时间 | "没有血流下，因为血还未及流下来。" |
| 只写结果 | 零招式，零动作分解 | "剑已刺入咽喉。"而非"他向左一闪，反手一剑" |

### 8.4 L4 约束检查清单（审查官面具）

```
□ CA-02 检查：是否有独立成段的极短句？是否有留白？
□ CA-03 检查：若有武打，是否零招式？是否只写速度/意境/结果？
□ CA-05 检查：对话是否足够短促？是否有潜台词？
□ SA-01 检查：是否有道家"大道至简""无为"的语言痕迹？
□ SA-03 检查：环境描写是否以气象/声音/细节服务心境？
□ 节奏检查：段落长短是否交错？是否有诗化意象叠加？
□ 标记词检查：对话提示词是否恰当使用（冷冷道/缓缓道等）？
□ 正面特征检查（v2 新增）：
  □ 每300字是否包含至少1个标志性技法？（独立短句/意象叠加/留白/潜台词/以X写Y）
  □ 若连续300字无任何标志性技法 → 标记为"风格真空"，必须插入至少1处
□ 风格疲劳度检查（v2 新增）：
  □ 同一段内"冷冷道"是否出现超过1次？
  □ 同一段内同一意象（如"刀""雪"）是否重复超过2次而无变奏？
  □ 同一场景内是否使用超过2种相同的标记词？
  □ 任一疲劳项触发 → 要求变奏：替换标记词/变换意象/调整句式
```

### 8.5 读者情感效果验证（v2 新增）

所有风格检查通过后，增加最后一道关卡：**读者视角验证**。

```
【读者面具切换】
现在请摘下"审查官"面具，戴上"第一次读这本书的读者"面具。
你完全不知道后续情节，只凭这段文字作答：

1. 读完这段，我感到______（寂寞/悬念/震撼/困惑/无感）
2. 这段文字中，最让我印象深刻的意象是______
3. 我想继续读下去的意愿是______（强烈/一般/不想）

若答案中出现"无感"或"不想"，说明文字合规但缺乏灵魂。
请回到"作家"面具，重写核心段落，直到读者产生预期的情感反应。
```

### 8.6 L4 纠偏规则（含修正成本评估）

| 偏离类型 | 严重程度 | 修正成本 | 纠偏动作 |
|---|---|---|---|
| 段落过长（>150字无断句） | Major | 低（拆分即可） | 自动拆分，插入短句段落 |
| 对话过长（单句>30字） | Major | 低（压缩即可） | 自动压缩至15字内 |
| 出现招式描写 | Critical | 低（删除替换） | 立即删除，替换为意境/速度/结果 |
| 环境白描（景观描写） | Major | 中（需重写） | 改为"以X写Y"技法 |
| 对话直白无潜台词 | Major | 中（需构思） | 为每句对话增加一层"言外之意" |
| 风格真空（300字无标志性技法） | Major | 中（需插入） | 在关键位置插入1处独立短句或意象叠加 |
| 标记词/意象疲劳 | Minor | 低（替换即可） | 替换为同义变奏 |
| 读者反馈"无感" | Critical | 高（需重写核心段落） | 返回场景预演层，重新设计核心张力 |
| 背离主题宣言 | Critical | 高（需重新锚定） | 回溯至L3调整场景定位，或调整L2主题锚定图 |

## 十、偏离检测与自动纠偏系统 v2

### 10.1 检测维度扩展（v2 新增正面特征检测）

```
function detect_deviation_v2(text, layer) {
    // ========== 负面偏离检测（保留v1）==========
    
    // CA-01: 历史化检测
    if (text.match(/(宋|元|明|清|朝|皇帝|朝廷|国家|民族)/)) 
        return {type: "CA-01", severity: "critical", cost: "low", action: "删除朝代/国家相关描述，替换为抽象时空"};
    
    // CA-03: 招式检测
    if (text.match(/(招式|剑法|刀法|拳法|第.*式|运起内力)/)) 
        return {type: "CA-03", severity: "critical", cost: "low", action: "删除招式描述，改为速度/意境/结果"};
    
    // CA-05: 对话过长检测
    let dialogues = extract_dialogues(text);
    let long_dialogues = dialogues.filter(d => d.length > 25);
    if (long_dialogues.length / dialogues.length > 0.3) 
        return {type: "CA-05", severity: "major", cost: "low", action: "缩短对话至25字以内，增加潜台词"};
    
    // SA-03: 环境白描检测
    if (text.match(/(高.*丈|宽.*尺|有.*间|布置|陈设|家具)/)) 
        return {type: "SA-03", severity: "major", cost: "medium", action: "删除景观描写，保留氛围暗示"};
    
    // ========== 正面特征密度检测（v2 新增）==========
    
    // 标志性技法计数
    let techniques = {
        short_sentence: count_independent_short_sentences(text),  // 独立短句
        image_overlay: count_image_overlays(text),               // 意象叠加
        ellipsis: count_significant_ellipsis(text),              // 留白/暗示
        subtext: count_dialogue_subtext(text),                   // 潜台词
        x_writes_y: count_x_writes_y(text)                       // 以X写Y
    };
    
    let total_techniques = Object.values(techniques).reduce((a,b) => a+b, 0);
    let word_count = count_words(text);
    
    // 风格真空检测：300字内无任何标志性技法
    if (word_count > 300 && total_techniques === 0) 
        return {type: "POS-01", severity: "major", cost: "medium", action: "插入至少1处独立短句或意象叠加"};
    
    // 正面特征稀疏检测：300字内只有1个技法
    if (word_count > 300 && total_techniques <= 1) 
        return {type: "POS-02", severity: "minor", cost: "low", action: "增加1处标志性技法（意象叠加或留白）"};
    
    // ========== 风格疲劳度检测（v2 新增）==========
    
    // 标记词重复检测
    let dialogue_tags = extract_dialogue_tags(text);
    let tag_counts = count_frequencies(dialogue_tags);
    for (let [tag, count] of Object.entries(tag_counts)) {
        if (count > 1 && text.length < 1000)  // 同一段内同一标记词出现超过1次
            return {type: "FAT-01", severity: "minor", cost: "low", action: `替换重复的"${tag}"为其他标记词`};
    }
    
    // 意象重复检测
    let core_images = extract_core_images(text); // 雪、刀、月等
    let image_counts = count_frequencies(core_images);
    for (let [img, count] of Object.entries(image_counts)) {
        if (count > 2 && text.length < 1500)  // 同一段内同一意象重复超过2次
            return {type: "FAT-02", severity: "minor", cost: "low", action: `变换"${img}"的意象表达，避免重复`};
    }
    
    return {type: "none", severity: "none", cost: "none"};
}
```

### 10.2 纠偏执行流程 v2

```
检测到偏离
    ↓
查询修正成本：
    - 低成本（low）：自动修正，继续生成
    - 中成本（medium）：标记问题，提供具体修改建议，AI修正后重检
    - 高成本（high）：标记问题，提供重写策略建议，返回上一层或预演层
    ↓
判断严重程度+成本：
    - Critical + any cost：拒绝该层输出，返回重写
    - Major + low cost：自动修正
    - Major + medium cost：要求修正后重检
    - Major + high cost：提供重写策略
    - Minor：自动修正，记录日志
    ↓
输出修正后的内容
    ↓
重新运行检测，直至通过
    ↓
通过所有检查 → 运行读者情感效果验证
    ↓
读者验证通过 → 完成该层
读者验证不通过 → 返回场景预演层，重新设计核心张力
```

### 10.3 重写指令模板 v2

#### Critical + 高成本 重写指令（读者"无感"）：
```
【偏离警告：读者情感真空】
这段文字通过了所有风格检查，但读者验证反馈为"无感"。
这意味着：文字合规，但缺乏灵魂。

可能原因：
1. 核心张力不足——场景没有真正的冲突或悬念
2. 意象陈词滥调——用了常见的比喻而非独特的感知
3. 情感距离过远——留白过度，读者无法代入

修正策略（返回场景预演层）：
1. 重新定义场景的核心张力：这个场景中，什么在撕裂？什么在对抗？
2. 替换平庸意象："雪很大"→"雪落满了他的睫毛，他没有眨眼"
3. 增加一个"刺点"：一个让读者心头一紧的细节

禁止：继续在当前段落上做表面修改。必须回到预演层重新设计。
```

2. 约束检查报告（逐项通过状态 + 修正成本标注）
3. 偏离检测结论（通过/需修正/严重偏离）
4. 读者情感验证结果（仅L4）
5. 跨章记忆矩阵更新（仅每章完成后）
```

开始新章节生成循环：

3. 按章纲逐个场景生成：
   a. 确认场景预演脚本
   b. 佩戴"作家"面具，展开为完整段落（L4规范 + 动态风格密度）

   e. 三项全部通过 → 继续下一场景
   f. 任一未通过 → 根据修正成本决定：自动修正 / 重写场景 / 返回预演层
4. 全章场景完成后：
   a. 输出整章
   b. 佩戴"档案管理员"面具，更新跨章记忆矩阵
   c. 输出全章检查报告 + 矩阵更新
```
