## 一、《长安月》

**主题：羁旅思乡**

```
[Verse 1]
驼铃声远 消失在荒凉古道边
大漠孤烟 勾勒出落日的弧线
羌笛声咽 杨柳依依攀折了谁的手腕
长安月冷 千家万户灯火照不亮我眼

[Pre-Chorus]
故园的炊烟 飘过几重山
母亲的白发 是否又多了几圈

[Chorus]
长安月 故乡的月
隔着一千里风沙的夜
我在塞外听你听过的胡笳声
抬头却看不见 同一个月

长安月 千年的月
照过李白也照过离别
历史的长卷翻了几页
只有那轮月 没有改写

[Verse 2]
驿站的酒 斟不满行囊的空缺
玉门关外 黄沙吞没了多少誓言
羌管悠悠 霜雪落在苍茫的关山
故园的桂花 香不过这一杯浊酒的时间

[Chorus]

[Bridge]
月落乌啼 姑苏城的钟声敲了千年
我却只能在月光里 辨认家的脸

[Outro]
长安月圆 人未圆
这轮月啊 载不动 游子的怨
```

## 二、《青石巷》

**主题：时光里的青梅竹马**

```
[Verse 1]
那年雨巷 你撑着油纸伞
青石板湿漉漉 映出你的裙边
我们踩过水洼 数着一二三四天
以为日子会这样 永远慢慢悠悠的 连

[Pre-Chorus]
后来我们都走散 在人海的弯弯绕绕
巷口的桂花树 开了几遭

[Chorus]
青石巷 青石巷
藏着多少 回不去的时光
你发梢的雨 和我眼里的伤
都被那口老井 慢慢收藏

青石巷 青石巷
巷尾的灯笼 还摇晃着昏黄
岁月染白了门楣上那副对联
却染不白 我心中的 那一声蝉

[Verse 2]
三十年后 我又回到这条巷
老槐树下 坐着谁的爹娘
隔壁的丫头 长得像你小时候模样
只是油纸伞 已换成花格子伞的模样

[Bridge]
你去了哪里 嫁给了谁
青石板上 我的脚步 还在等回音
木门斑驳 锁不住一巷的苔痕
却锁住了 我所有想说的曾经

[Chorus]

[Outro]
青石巷啊 你记得吗
有两个人 曾在这里说过
要做一辈子的 邻居
```

## 三、《扁舟》

**主题：江湖漂泊与归隐**

```
[Verse 1]
一叶扁舟 江上漂流
两岸猿声 啼不过心里的愁
船头的老翁 钓着黄昏的悠悠
鱼篓空空 不问收获 只问清幽

[Pre-Chorus]
江湖多少年 我忘了姓氏
剑鞘生锈 不记得 为谁出鞘过

[Chorus]
扁舟扁舟 载我到何方
是那芦苇荡 还是梦里的水云乡
卸下剑与酒 披上蓑衣与星光
这一蓑烟雨 任凭它落在肩上

扁舟扁舟 我不问航向
随波逐流也是一种 收与放
两岸青山慢慢往后退
我慢慢往 心的方向 退

[Verse 2]
夜泊枫桥 钟声穿过渔火袅袅
客船上的过客 都在聊什么寂寥
而我只管 掬一捧江水洗去风尘
让月光 照见我久违的 微笑

[Bridge]
如果可以 我愿做这江上
最后一盏渔火 不问来处
只照亮 下一段 无人的路
让所有漂泊 都找到 停泊的理由

[Chorus]

[Outro]
江月照了千年 扁舟过了千帆
而我只想 在这水云间
做一个 不赶路的 旅人
```

## 四、《胭脂扣》

**主题：乱世绝恋**

```
[Verse 1]
十里洋场 霓虹灯摇晃
她站在戏台上 水袖一甩
演尽了悲欢 却演不完自己的孤单
那枚胭脂扣 系在红绳上 攥在谁指尖

[Pre-Chorus]
他要去打仗 她要来送行
一句等我 成为最残忍的约定

[Chorus]
胭脂扣 扣不住的流年
她用十年 等一封字迹模糊的信笺
扣不住他 扣不住明天
只有这枚扣子 陪她老在 阁楼里面

胭脂扣 扣住了思念
那年他亲手 系在她腕间
胭脂红得正浓 像一场来不及的缘
扣啊扣 把两个人扣在 不同的生死线

[Verse 2]
战火纷飞 他埋骨在何方
她只能对着旧照片 偷偷端详
那枚扣子 已经退了色
她的唇 也褪去了当年的 胭脂香

[Bridge]
后来有人告诉她
他在最后那场仗前 把它托人寄回
信里只有一句：对不起
她把扣子 贴在胸口 从此不再解下

[Chorus]

[Outro]
如果来生 我们还能相见
我不做戏子 你不做英雄
只在寻常巷陌 卖豆浆和葱油饼
让这枚扣子 永远系在 你的手腕
```

## 五、《古祠》

**主题：历史与文物古迹的感慨**

```
[Verse 1]
石碑上刻着谁的名字
风化了几个朝代的雨
断碑残垣 是谁留下的笔记
我蹲下来 用指腹轻轻辨认

[Pre-Chorus]
他们曾经 也爱过恨过活过
在这同一片土地 繁衍生息过

[Chorus]
古祠古祠 你是谁的家
牌位上那些名字 我从未听说
他们的一生 被写进几行青石
被我们读着 却再也叫不醒 他们

古祠古祠 你藏着多少秘密
屋檐上的神兽 看惯了改朝换代
梁上的燕子 飞了多少代
只有这香炉里的灰 还温着 从前

[Verse 2]
钟声响起 惊起檐下栖息的鸟
它们飞过城墙 消失在旧时光的隧道
我站在院子中央 想象他们的模样
在同一个位置 看同样的月亮

[Bridge]
历史没有声音 却比任何语言更响
这些斑驳的墙 是时间写下的注脚
我们路过 惊叹 然后遗忘
而古祠 依然在这里 守着自己的悲伤

[Chorus]

[Outro]
如果文物会说话
它会告诉你：别把我当成景点
我曾是一个家 住过活生生的人
请在你的目光里 放一点 敬畏的温度
```
